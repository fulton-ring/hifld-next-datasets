# Miscellaneous Industrial Mineral Operations — parked: no maintained USGS producer publication

Assigned dataset: USGS National Atlas *Miscellaneous Industrial Minerals Operations* layer (`minop5x020`, publication 200512, Minerals Information Team operations surveyed as active in 2003), identified by the surviving USGS legacy FGDC metadata at https://thor-f5.er.usgs.gov/ngtoc/metadata/waf/atlas_legacy/minop5x020.xml (20,018 bytes, SHA-256 `1ff2b2c8910aca0fe86e3241c0c3c3e1c45a24c396c4401c074c110a98b7c9ee`, metadata date 20060713; byte-verified by anonymous retrieval 2026-11-16). Producer scope pinned from that document: 304 entity points; identifier `Minop5x020` 1..305; `Plant_min` domain M (mine), M/P (mine and plant) and P (plant); fifteen commodity classes Barite, Bromine, Diatomite, Fullers earth, Iodine, Iron oxide pigments, Kaolin, Lime, Lithium, Salt, Soda ash, Sodium sulfate, Titanium dioxide pigment, Titanium minerals, Trona; declared latitude range 25.925..48.565 and longitude range -122.782..-73.112; NAD83 decimal degrees; "Facilities that extract, process, and (or) distribute miscellaneous industrial minerals."

## Why the dataset is parked (dated evidence)

- **Original producer release retired.** `http://dds.cr.usgs.gov/pub/data/nationalatlas/minop5x020_nt00022.tar.gz` (named by the surviving FGDC `onlink`) returns 404 on the live USGS endpoint (first observed 2026-11-10 and re-verified 2026-11-16 after the host's http→https redirect). The inventoried DataLumos project 239600 V1 is a banned archive source and was never fetched. No third-party mirror was used.
- **Producer survey publication is a one-time release, not a maintained successor.** The USGS-owned https://mrdata.usgs.gov/mineplant/mineplant.zip — *Active Mines and Mineral Processing Plants in the United States in 2003* (National Minerals Information Center; 513,191 bytes, SHA-256 `6dabd3bbedcb1fbf0c5155fb349228951a9b2cbd065311484eb479c25997ee4e`), its CSV package https://mrdata.usgs.gov/mineplant/mineplant-csv.zip (193,253 bytes, SHA-256 `aac018066ca3bb9b0c4ac40438c86901f80e27787b3b9ecdd4de9234d2e6b0b1`) and its FGDC metadata https://mrdata.usgs.gov/metadata/mineplant.xml (26,366 bytes, SHA-256 `419629edaf825f2d55ed1dd03fe3a9921d0d35a8240c208b44b53d30c8b9ead0`, metadata date 20201230) declare **progress "Complete"** and **update frequency "None planned"** with ground condition 2003 (verified by independent anonymous retrievals on 2026-11-16 matching the pinned digests). Under the current source policy a one-time release with no planned refresh is not a pipeline input; live agency hosting and a 2020 metadata date do not establish maintenance.
- **Same survey scope, different record identity.** The producer CSV's fifteen-commodity filter yields exactly 304 rows with per-commodity counts identical to the archived layer's recorded facts (Lime 89, Salt 68, Barite 29, Kaolin 28, Fullers Earth 24, Iron Oxide Pigments 19, Diatomite 11, Titanium Dioxide Pigment 10, Bromine 7, Soda Ash 7, Titanium Minerals 5, Iodine 3, Sodium Sulfate 2, Lithium 1, Trona 1; 43 states; Plant_min M 37 / M-P 164 / P 103; re-derived from the producer CSV 2026-11-16). It is still a different product: CSV `id` 1..6841 (6,785 rows) instead of the `Minop5x020` 1..305 roster (304 rows, one producer gap at 187), one multi-commodity site split into two rows, and 3-decimal coordinate export instead of the archived DBF's 6-decimal values — so adopting it would change the dataset's record identity and precision rather than reconstruct the layer.
- **Current producer alternatives checked:**
  - *Mines, smelters, refineries, and recycling facilities in the United States* (USGS NMIC, DOI 10.5066/P1BUPUAM, ScienceBase item 6a3edaf71ba49b7c2e263528, published 20260629, data period 20241204..20260430): a current tabular worksheet that publishes **no coordinate columns** (location is town/state text), so it cannot recreate this entity-point layer; its own FGDC metadata also declares progress Complete and update None planned (verified by dated project research 2026-11-13; item re-checked 2026-11-16).
  - *Mineral Resource Data System (MRDS)* (mrdata.usgs.gov/mrds/): dated prior project research (2026-11-12) — updates ceased and the product is a materially different global deposit database.
  - *USMIN mineral deposit areas* (mrdata.usgs.gov/deposit/): dated prior project research (2026-11-12) — developing critical-minerals product, different scope.
  - *ScienceBase and TNM Access searches* (2026-11-16): no ScienceBase item for `minop5x020` or "Miscellaneous Industrial Minerals Operations"; no current USGS distribution of the retired layer was found there.

No maintained USGS producer publication capable of reconstructing this layer is known, so per the current source policy the dataset is parked. `src/dagster_hifld/sources/miscellaneous_industrial_mineral_operations.py` keeps only the pinned producer-contract facts and the fail-closed refusal (`no_maintained_producer_publication_park_or_retire`); it defines no fetching, decoding, staging or candidate output, and every materialization attempt fails closed. The registered ingest asset fails closed and the monthly schedule is STOPPED.

## Resuming requires an explicit maintainer decision

One of: park permanently; retire the dataset; accept an explicitly provided preserved capture of the original producer archive (the ferrous-siblings route, with capture provenance outside banned hosts); or name a maintained producer source. If USGS ever publishes a different release status for the mineplant metadata document, `parse_mineplant_release_status` fails closed with a re-evaluation error instead of absorbing the change; if the surviving legacy scope document ever drifts (title, publication date, download link, entity count, identifier range, plant/mine domain, commodity classes, declared coordinate ranges, datum), `parse_atlas_scope` fails closed the same way.

## Research context retained (comparison only, never inputs)

No copy of this dataset is published by this project, so there is no published v1 object to compare. The archived producer package's decoded native facts were recorded by the superseded draft of this dataset (PR #717 head 69b4ba38, 2026-11-10) and are retained here as research context only: 304 point features; DBF fields `MINOP5X020 N(3,0)`, `COMMODITY C(24)`, `SITE_NAME C(57)`, `COMPANY_NA C(39)`, `STATE_LOCA C(14)`, `COUNTY C(16)`, `LATITUDE N(15,6)`, `LONGITUDE N(16,6)`, `PLANT_MIN C(10)`; `MINOP5X020` roster 1..305 with exactly one producer gap at 187; SHP bbox -122.7832108803277 25.925357918190876 -73.11154741972673 48.56498476259746 (NAD83); DBF attribute values producer-rounded against SHP XY (max 0.00123 deg); one Windows-1252 0x92 byte in the bundled FGDC text ("fuller's earth"). The other seven National Atlas mineral-operations layers' commodity classes (agricultural, construction, ferrous mines, ferrous processing plants, nonferrous mines, nonferrous processing plants, refractory/abrasive — read from their surviving legacy FGDC documents 2026-11-16) are pinned in the module as excluded commodity classes so a wrong-layer substitution fails closed; Diatomite and Trona are shared with the refractory/abrasive layer, so they remain part of this layer's own roster rather than exclusion indicators.
