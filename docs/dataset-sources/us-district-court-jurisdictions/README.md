# US District Court Jurisdictions source record

- Inventory ID: `us-district-court-jurisdictions` (issue #366). No pipeline is implemented for this dataset: DHS HIFLD officially retired the layer, the crosswalk-listed agency (Federal Judicial Center) publishes only a static boundaries map, and no producer (DOJ, Administrative Office of the U.S. Courts, FJC) maintains a machine-readable boundary product. All complete surviving copies live on banned hosts or non-producer ArcGIS accounts. Park/retire is a supervisor/maintainer decision (`needs_decision`: "no maintained source: park or retire").

- Reconstruction note: the 94 district polygons are statutorily composed of counties (28 U.S.C. §§ 81-131) and could in principle be re-derived by dissolving maintained Census TIGER county polygons along a county-district membership table, but no agency publishes that membership as a machine-readable dataset (the statute is text; the courts' CM/ECF lookup is a court-point service). Such a rebuild would be a new, materially different product (different geometry lineage and schema, no HIFLD attribute contract) and therefore a separate explicit maintainer decision, not a default input substitution.
- Audit trail: no ingest, catalog or publish assets exist for this dataset and none were created; this file is the only change this issue contributes to `main` pending the supervisor decision (consistent with the sibling source records for the retired-HIFLD family, e.g. `uscg-districts` #373 / PR #886 and the park/retire flow).
