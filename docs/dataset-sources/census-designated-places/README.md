# Census Designated Places draft

This implements the exact inventory layer, `Census_Designated_Place`, in the Census Bureau's still directly distributed 2024 national substate FileGDB. It is a reconstruction of that historical edition. The stopped monthly schedule re-observes the pinned publication; it does not pretend that a new fetch updates boundaries. A changed upstream ZIP or new annual edition requires review and a new explicit pin and compatibility decision.

The complete original ZIP is retained once in the isolated staging raw depot. GDAL reads only the named layer through `/vsizip`; unrelated GDB layers are not expanded or substituted. All 12,884 CDPs, original OBJECTIDs, PLACENS, GEOID and GEOIDFQ strings, native Double area fields, source field declarations and NAD83 MultiPolygon coordinates are preserved. The complete release contains 53 state/territory codes, including Hawaii, Guam, Puerto Rico and the U.S. Virgin Islands. Original OIDs have a producer physical width of four bytes; GDAL/Arrow's int64 representation is explicitly proposed rather than silently declared approved.

The complete published candidate has 12,896 rows and a different schema/CRS/identifier space. Of 12,863 diagnostic common GEOIDs, zero original OBJECTIDs agree. There are 21 source-only and 33 published-only GEOIDs. Every original published ID remains in the independently retained baseline. No ID mapping, column renaming, numeric cast, geometry repair, source replacement or release is accepted by this draft.

`source.json` records authority, pins, completeness and decisions. `evidence/baseline-comparison.json` records the complete comparison. Crosswalk access returned provider403, so its match remains unverified; it is not called an unmatched result. The inventory's 2023 metadata URL returned404. The original inventory itself explicitly identifies the 2024 FileGDB and layer.

Local execution uses explicit isolated staging/output and the normal Dagster graph. Set `HIFLD_CDP_ARCHIVE` and `HIFLD_CDP_RECEIPT` to the complete captured original/receipt for deterministic replay. When unset, the adapter makes one bounded complete live acquisition and preserves failed partial bodies. Memory and storage guards fail closed. Capture failures never erase prior versions. Native GeoParquet is pinned under the shared prebuilt policy so generic conversion cannot add fields or coerce types; this capability is not approval. Shapefile regeneration and PMTiles remain explicitly unsupported pending mapping decisions.

The source adapter serializes lookup, full cache verification, whole-invalid-version quarantine and atomic installation using one stable lock. Cached GPKG bytes are fully regenerated from the pinned source, including SRS, geometry headers, RTree and auxiliary tables. Arrow physical/field metadata and every row's attributes and native WKB are compared. Source-owned reports, wrappers, an explicitly unapproved baseline placeholder, raw references, original construction manifest and code identity are bound independently; a missing first-construction binding cannot be reconstructed from a cached claim. Accepted production storage is never a valid target.

The complete baseline geometry audit found 38 invalid historical geometries and a Polygon/MultiPolygon mix. A separate, explicitly diagnostic NAD83-to-WebMercator transformation found zero exact-coordinate matches for all 12,863 common GEOIDs and zero topology-equal geometries among the 12,825 valid comparable pairs. This transformation never enters candidate construction. All original source/baseline geometries remain preserved independently.
