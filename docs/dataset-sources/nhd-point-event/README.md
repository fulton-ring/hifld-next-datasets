# NHD Point Event source record

- Inventory ID: `nhd/point-event-2` (issue #227). No pipeline is implemented for this dataset: the exact producer publication is a retired historical release and no currently maintained agency publication recreates it. Park/retire is a supervisor decision (`needs_decision`: "no maintained source: park or retire"), consistent with the sibling dispositions on #217 (PR #813), #232 and #231.
- Crosswalk match: the DHS HIFLD Open crosswalk (DOI 10.3886/E241367V1) consolidates the NHD-family rows into one "3D Hydrography Program (3DHP) Layers" row whose Open REST service is the USGS `3dhp.nationalmap.gov` `usgs_3dhp_all` FeatureServer; the byte-identical public copy is sha256 `7f3394fed2712fdcc176b7ce658293fdded656b9b719f0d90154c07dc38772bc`. The HIFLD inventory description for this row is the legacy USGS NHD service description verbatim, prefixed "Please use 3DHP for updated data", with agency "US Geological Survey"; the inventory Download Location is the DataLumos project 240396 third-party mirror, which was never fetched.
- Exact producer publication (identified, not used as a pipeline input): USGS NHD MapServer layer 1 "Point Event", `https://hydro.nationalmap.gov/arcgis/rest/services/nhd/MapServer/1` — point layer, served Web Mercator (102100/3857), anonymous REST, maxRecordCount 2000 with pagination. Live checks 2026-11-13 (anonymous): 285,690 features (`returnCountOnly`, re-verified 2026-11-13); 16 fields OBJECTID, SHAPE, EVENTDATE, REACHSMDATE, REACHRESOLUTION, FEATURECLASSREF, SOURCE_ORIGINATOR (130), SOURCE_DATADESC (100), SOURCE_FEATUREID (100), FEATUREDETAILURL (255), EVENTTYPE, REACHCODE (14), PERMANENT_IDENTIFIER (40), FEATURE_PERMANENT_IDENTIFIER (40), EVENTOFFSET, MEASURE, GLOBALID (38) — the NHD reach-event contract (events referenced to reaches by REACHCODE + MEASURE/EVENTOFFSET), not the 3DHP id3dhp-era schema. 100% REACHRESOLUTION = 2 ("High", 1:24,000-source) across all features; EVENTDATE range 2007-03-16 .. 2023-11-13 (min/max statistics); SOURCE_DATADESC mix: NWIS stream-gage events 221,282; photo interpretation 58,337; state water-resources and dam-safety programs (Wyoming 1,546, Oklahoma 549, Washington 195, Colorado 949, California/CDWR, CAP/USBR/NID dam inspections). Service copyright reads "USGS TNM – National Hydrography Dataset. Data Refreshed October, 2026."
- Retirement evidence (checked 2026-11-13): USGS states "As of October 1, 2023, the NHD was retired. NHD data will continue to be available, but no longer maintained. The most current data will be available through the 3D Hydrography Program (3DHP)" (https://www.usgs.gov/national-hydrography/national-hydrography-dataset); the 3DHP products page classifies the legacy NHD services and downloads as "no longer updated and maintained" and provided "for reference purposes" (https://www.usgs.gov/3d-hydrography-program/access-3dhp-data-products). The October 2026 "Data Refreshed" line is periodic republication of the same static legacy content, not data stewardship: the layer's last event content (EVENTDATE max 2023-11-13) predates the 2023-10-01 retirement by weeks. The reviewed sibling source records in this dataset family (#220, #225, #226, #232, #231, #217/PR #813) and the #806 review ruling established the retired reference publication as unacceptable as a pipeline source.
- Maintained-successor check (checked 2026-11-13): the USGS 3DHP_all FeatureServer (`https://3dhp.nationalmap.gov/arcgis/rest/services/usgs_3dhp_all/FeatureServer`, service copyright "Data refreshed September 4, 2026", re-verified live 2026-11-13) publishes layers 20/30/40 HydroLocation, 50 Flowline, 60 Waterbody, 80 Catchment, 90/92/94 Spatial Metadata — no point-event layer. 3DHP HydroLocations are network-mapping points (headwater/terminus/divergence/confluence/catchment outlet, sink/spring/waterbody-outlet, external connection — separate inventory rows, e.g. #224/#223), not the NHD reach-event corpus; the 3DHP id3dhp data model has no REACHCODE/MEASURE/EVENTTYPE/SOURCE_* contract.
- NHDPlus_HR check (checked 2026-11-13): the NHDPlus_HR MapServer (copyright "Data refreshed October, 2022"; NHD-derived snapshot; per the #220 evidence it covers only portions of Alaska) hosts NHDPlusGage and NHDPoint but no Point Event layer.
- EPA NHDPlusV2 check (checked 2026-11-13): the frozen 1:100k legacy build (V2.1 user guide 2019-03-13; territory snapshots frozen 2015-2016) does not carry the national high-resolution point-event table.
- Mirror policy: the DataLumos/ICPSR archive entry cited by the issue is a third-party mirror and was never fetched; no archive or mirror is a pipeline candidate.
