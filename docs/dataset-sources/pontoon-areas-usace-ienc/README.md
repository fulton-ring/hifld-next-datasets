It describes USACE/AGC bi-monthly IENC updates, directly links the USACE IENC master geodatabase and official Feature Classes service directory, and warns that chart-derived features may contain inaccuracies. The source Feature_ID field has one duplicate among 607 rows; the duplicate value is preserved verbatim, and OBJECTID remains the row identifier. This is the complete observed IENC chart feature class, not a nationwide inventory of pontoon structures. The layer provides no edition or release date. The BTS update cadence is separate from retrieval date.
