# Current DART Deployments — working draft pipeline

This PR implements a complete source-specific local draft, not release acceptance. The user's implementation correction supersedes the issue's original research-only/contract-before-code sequence. Maintainer source, historical baseline, identifier, schema/physical-type and format decisions still block promotion; nothing approves production publication or a destructive mapping.

NOAA's NCEI hazards map loads `index-Cyvq2L9n.js`, whose import explicitly selects `store-CeovILYQ.js`, which selects webmap `5cb326668189408e8c4c20ddd92aa2ed`. The captured webmap's exact `current-dart-deployments` layer points to the NCEI `ncei_noaa` hosted item `764d3a99a4f8440ea05522815b5f5e19`, layer 0. This is explicit producer delegation to Esri distribution, not an inferred NOAA ownership claim from a portal title. All 12 original responses and dated receipts are retained. Portal modification and layer `editingInfo` timestamps are not a declared data release date.

The complete layer has 62 global sites: 40 `DEPLOYED=Y` and 22 `P`. It includes planned sites and international locations; it must not be relabeled as 39 currently operational US-owned buoys. Before/after independent counts and OBJECTID rosters match all 62 rows with no transfer-limit flag. The six attributes preserve `STATION`, `OBJECTID`, `OID`, `DESCRIPTION`, `DEPLOYED` and `DATA_URL`; three identifiers are stored as source-declared int32 and every native EPSG:3857 XY coordinate survives. Native GeoPackage and typed GeoParquet are constructed deterministically. Native GeoParquet reuse is explicitly pinned through the shared prebuilt-output policy, retaining widths and metadata without an unapproved generic conversion.

The complete captured published v1.0.0 GeoJSON, GeoPackage and GeoParquet candidates each contain the same 62 station values. Five common attributes match every row, including the original `OID`, but all 62 current source `OBJECTID` values differ from published GeoJSON `OBJECTID`. None of the 62 published GeoParquet WKB values exactly match source coordinates; the largest coordinate difference is approximately 0.0000498053 native meters. Published Parquet widens source IDs to int64 and omits OBJECTID; GeoJSON retains it and GeoPackage retains an intrinsic FID. Every original published file is preserved separately; the station correspondence in the audit is diagnostic, not an accepted join or mapping. `evidence/audit.py` reproduces the complete row-level identifier and schema inventory.

The NOAA-hosted legacy hazards MapServer layer8 is separately captured in runtime evidence and exposes 10 attributes, including additional date/depth/position fields. It is not silently substituted for the exact six-column NCEI webmap layer. NDBC active-stations XML responds200, while `dart.shtml` responds403; neither is substituted for this dataset's complete publication. The DHS crosswalk DOI redirects to DataLumos project241367 and returns origin403, so exact crosswalk contents remain explicitly unverified. The exact inventory archive project239073 appears in the published collection's `derived_from` link, and title/description/current official webmap lineage match. The crosswalk is not fabricated or marked reviewed.

Source drift, incomplete counts/IDs, changed schema/CRS, extra dimensions, invalid geometry or changed feature bytes fail closed into retained quarantine. Refresh revalidates the complete original source; a pinned namespace is reused only after independently rebuilding native rows, the whole GeoPackage container, typed Parquet, provenance and all source-owned comparison reports. A separate immutable construction binding prevents a cache from inventing its original code commit. Missing ready markers detach the entire incomplete version under the common kernel lock. Private installation and validation share that lock; a losing installer cannot quarantine a valid concurrent winner. Historical versions are never rewritten.

The proposed weekly source-only schedule remains stopped. Draft extraction requires explicit local staging and rejects published/GCS storage. Standard catalog/publish asset checks and the independent approval registry remain mandatory. Synthetic quality failures and local sentinel fixtures establish behavior only; they do not approve any real candidate. Local Dagster run evidence and exact-head review are recorded in subsequent evidence files and issue/PR updates.
