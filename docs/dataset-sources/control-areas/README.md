# Control Areas source record

The historical HIFLD record is DataLumos project 239072, version V1. Its description calls the features electric power control areas and also uses “Balancing Authority Areas,” but the pinned published collection contains no original source URL or source manifest with lineage. The pinned collection reports 71 MultiPolygon features, WGS 84, and 28 invalid geometries; these are historical candidate diagnostics, not an accepted baseline.

On 2026-10-19, the official U.S. Energy Information Administration Energy Atlas V3 dataset API returned HTTP 200 with an empty `data` array for exact slug filters `control-areas`, `balancing-authority-areas`, and `electric-balancing-authority-areas`. The Atlas API was reachable. ArcGIS Online item search for “Control Areas” with “Energy Information Administration” returned four unrelated Esri Policy Maps items; the “Balancing Authority Areas” search returned no EIA-owned item. The exact HTTP response bodies, response headers, request URLs, UTC observation times and SHA-256 hashes are retained outside Git under `/tmp/hifld-native-reconstruction/43/source_discovery/`. These catalog queries are scoped evidence, not proof that no source exists globally. Energy Atlas and ArcGIS search results do not establish an official source or successor relationship for the historical polygons.

## Producer identified (2026-11-12)

The layer is part of the multi-laboratory “Electric Foundation Energy Data” product. The retired HIFLD Open feature service metadata (NASA NCCS mirror, service item `19c8b69eedae4fdbb31fee200a8c1b55`, layer `control_areas` id 23) credits the copyright text to the Oak Ridge National Laboratory (ORNL) Geographic Information Science and Technology (GIST) Group, Los Alamos National Laboratory (LANL), Idaho National Laboratory (INL), and the National Geospatial-Intelligence Agency (NGA) Homeland Security Infrastructure Program (HSIP) Team. The DOE poster “Creating Foundation Electric Energy Infrastructure Data from Open-Sources” (Singh, Schmidt, Visarraga, Elliott; energy.gov, 2023) describes these layers — Control Areas among them — as government-owned, compiled from open sources (the layer’s own SOURCE values are FERC 714, EIA 860, EIA 861, Census TIGER/Line), distributed without restriction through HIFLD, and updated annually until the platform was retired. DataLumos lists the dataset’s authors as DOE Office of Science ORNL and DHS. No EIA/DOE successor feed publishes these polygons: re-checked 2026-11-12, the EIA Atlas v3 catalog enumeration (750+ public dataset records) contains no control-area or balancing-authority layer, and the sibling foundation layer the EIA Atlas hosted (Electric Retail Service Territories, service `f4cd55044b924fed9bc8b64022966097`) is now private behind a login, as are HIFLD’s own remaining channels (hub site item `786ca70c1b5e4fb0b1aa1f417b46d446` returns “not accessible”; gii.dhs.gov redirects there; HIFLD ArcGIS accounts expose no public items).

## Maintained redistribution candidate: ANL GEM (2026-11-12)

Argonne National Laboratory’s Geospatial Energy Mapper (https://gem.anl.gov, DOE Office of Electricity work under agreement DE-OE000316) currently distributes an exact copy of the final HIFLD release as catalog layer `electric_planning_area_hifld` version 2 (published under the mislabeled name “Electric Planning Areas”; its metadata PDF cites https://hifld-geoplatform.hub.arcgis.com/datasets/geoplatform::control-areas/about). Verified 2026-11-12 against the pinned HIFLD Next v1.0.0 baseline (comparison copy only, never an input): the GEM v2 GeoPackage holds 71 features; all 71 ID+NAME pairs match exactly, and TOTAL_CAP and SOURCE values are identical on every row; SOURCEDATE 2021-06-21 / VAL_DATE 2022-06-03 match the final October 2022 HIFLD release. The GEM download is public: https://gem.anl.gov/tool/r/conus/layers/electric_planning_area_hifld/versions/2/download.zip (sha256 of the fetched copy recorded outside Git with the retained artifacts). GEM’s own disclaimer states the platform is actively maintained but that its layers were gathered from publicly available sources and users should check with the original source; GEM therefore presents itself as a convenience redistribution, not as the producer. Decision required: whether ANL GEM qualifies as an acceptable official distribution for a faithful rebuild of this retired dataset, or whether producer/HIFLD-Secure access is pursued instead; no rebuild may substitute a mirror without that decision. No current feed, archive refresh, or partial substitute was used.
