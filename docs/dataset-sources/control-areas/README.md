# Control Areas source blocker

The historical HIFLD record is DataLumos project 239072, version V1. Its description calls the features electric power control areas and also uses “Balancing Authority Areas,” but the pinned published collection contains no original source URL or source manifest with lineage. The pinned collection reports 71 MultiPolygon features, WGS 84, and 28 invalid geometries; these are historical candidate diagnostics, not an accepted baseline.

On 2026-10-19, the official U.S. Energy Information Administration Energy Atlas V3 dataset API returned HTTP 200 with an empty `data` array for exact slug filters `control-areas`, `balancing-authority-areas`, and `electric-balancing-authority-areas`. The Atlas API was reachable. ArcGIS Online item search for “Control Areas” with “Energy Information Administration” returned four unrelated Esri Policy Maps items; the “Balancing Authority Areas” search returned no EIA-owned item. The exact HTTP response bodies, response headers, request URLs, UTC observation times and SHA-256 hashes are retained outside Git under `/tmp/hifld-native-reconstruction/43/source_discovery/`. These catalog queries are scoped evidence, not proof that no source exists globally. Energy Atlas and ArcGIS search results do not establish an official source or successor relationship for the historical polygons.

No geometry feed was found whose producer is EIA/DOE or a documented delegate, and no primary-source statement was found that the current balancing-authority areas are the historical Control Areas dataset’s successor. A current balancing-authority boundary service could not be substituted on terminology alone. Until that producer and lineage are established, there is no defensible source endpoint to capture, compare, or turn into a faithful refresh pipeline. No current feed, archive refresh, or partial substitute was used.
