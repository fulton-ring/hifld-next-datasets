# Conveyor Areas (USACE IENC)

The candidate reads the `CONVEYOR_AREA` polygon layer (MapServer layer 60) from the official [USACE IENC Feature Classes service](https://ienccloud.us/arcgis/rest/services/IENC_Feature_Classes/CONVEYOR_AREA/MapServer). The public [USDOT BTS IENC item](https://www.arcgis.com/sharing/rest/content/items/7ec34864c8804468a9cf52d437fe4b6c?f=json) describes bi-monthly USACE/Army Geospatial Center chart updates and links both the master geodatabase and feature-class services. That cadence does not identify this layer's edition or extraction date.

The observed layer is EPSG:4326 with 269 native OBJECTIDs and 11 declared non-geometry fields, including `Feature_ID`. The capture keeps every field, ID, and source polygon ring; it rejects count, ID, schema, layer, extent, or CRS changes. The output is an unapproved GeoParquet candidate for the inland IENC chart extent, not a nationwide conveyor-facility inventory. The [DataLumos/HIFLD historical record](https://www.datalumos.org/datalumos/project/239076/version/V1/view) is not treated as the current publisher, and equivalence between that record and this layer is unverified. Rights, baseline, edition, schema/ID contract, coverage, and release acceptance remain pending.
