# Landmark Areas (USACE IENC)

The inventory identifies the historical DataLumos V1 package (project 239456). A current public BTS IENC catalog record links the USACE IENC Feature Classes service and master geodatabase; the service identifies USACE IENC as copyright holder. This draft queries the service's `LANDMARK_AREA` MapServer layer 90 directly. That establishes a traceable current service source for the candidate, not continuity with the DataLumos/HIFLD records or approval of a successor.

The observed layer is a regional inland-chart dataset (6 polygon features, `OBJECTID` 1..6), not a nationwide landmark inventory. Its candidate retains the complete observed `OBJECTID` roster, all declared attributes including `Feature_ID`, and native closed polygon rings. Every feature query requests `returnZ=true` and `returnM=true`; the adapter validates the actual returned ring ordinates and fails closed on Z or M values. Source release date, historical baseline, schema/ID contract, coverage acceptance, rights, and release remain unaccepted. The refresh schedule is stopped.

The archived inventory modification date is not treated as a current source release date. The DHS crosswalk itself (doi 10.3886/E241367V1, DataLumos project 241367) was not anonymously retrievable on 2026-11-07 (ICPSR/DataLumos HTTP 403; the former GeoPlatform crosswalk item returns "Item does not exist or is inaccessible"), so no crosswalk match is claimed.
