# Lakes (USACE IENC)

This draft represents the exact `LAKE_AREA` polygon class (MapServer layer 76) in the official IENC Feature Classes service. The producer is the US Army Corps of Engineers, Army Geospatial Center. The public USDOT Bureau of Transportation Statistics IENC catalog item links the official service and master geodatabase; the service directory and layer are checked against their capture-time values before and after row extraction.

The live layer metadata reports 4,940 object IDs, eight non-geometry attributes, and EPSG:4326. A first feature-page capture did not complete, so no full source snapshot or data candidate has been produced. The intended source scope is inland electronic navigational chart coverage only. This draft does not claim all lakes in the United States, continuity with a historical HIFLD release, a producer release date, or a currentness interval. The DataLumos archive is a historical inventory reference, not the refresh source.

The observed layer metadata declares the full source attribute schema and identifier fields (`OBJECTID` and `Feature_ID`). A future complete candidate is intended to preserve their source values and native geometry without reprojection or repair; no feature values or geometry have yet been fully captured. The op config now supports a capture budget from 1 MB to 96 MB, defaulting to 8 MB. The same selected limit bounds each wire or decoded response and the cumulative retained wire and decoded bodies; additional reserve is required while reading. The incomplete first feature page does not demonstrate that the full 4,940-feature capture fits any configured limit. The selected limit is recorded with capture evidence and must match for retained-capture replay. Rights, vintage, baseline, schema/ID/coverage compatibility, and release acceptance remain pending. The refresh schedule is registered as stopped.
