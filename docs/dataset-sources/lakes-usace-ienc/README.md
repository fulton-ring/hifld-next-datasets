# Lakes (USACE IENC)

This draft represents the exact `LAKE_AREA` polygon class (MapServer layer 76) in the official IENC Feature Classes service. The producer is the US Army Corps of Engineers, Army Geospatial Center. The public USDOT Bureau of Transportation Statistics IENC catalog item links the official service and master geodatabase; the service directory and layer are checked against their capture-time values before and after row extraction.

The live metadata observed for this candidate reports 4,940 object IDs, eight non-geometry attributes, and EPSG:4326. The captured class is inland electronic navigational chart coverage only. This draft does not claim all lakes in the United States, continuity with a historical HIFLD release, a producer release date, or a currentness interval. The DataLumos archive is a historical inventory reference, not the refresh source.

The draft retains the full source attribute schema and identifiers (`OBJECTID` and `Feature_ID`) without reprojection or geometry repair. Rights, vintage, baseline, schema/ID/coverage compatibility, and release acceptance remain pending. The refresh schedule is registered as stopped.
