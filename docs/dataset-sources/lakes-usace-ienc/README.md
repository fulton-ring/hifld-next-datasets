# Lakes (USACE IENC)

This draft represents the exact `LAKE_AREA` polygon class (MapServer layer 76) in the official IENC Feature Classes service. The producer is the US Army Corps of Engineers, Army Geospatial Center. The public USDOT Bureau of Transportation Statistics IENC catalog item links the official service and master geodatabase; the service directory and layer are checked against their capture-time values before and after row extraction.

The layer metadata and completed source capture report 4,940 object IDs, eight non-geometry attributes, and EPSG:4326. The complete captured population was checked against its exact ID roster, native attributes, and polygon coordinates; source catalog quality and a post-catalog offline cache replay also passed. The candidate is for inland electronic navigational chart coverage only. It does not claim all lakes in the United States, continuity with a historical HIFLD release, a producer release date, or a currentness interval. The DataLumos archive is a historical inventory reference, not the refresh source.

The candidate retains source identifiers and all declared attributes in source order, including nullable integer `Scale_Minimum`, with native EPSG:4326 polygon geometry and no reprojection or repair. The op config supports a capture budget from 1 MB to 96 MB, defaulting to 8 MB; the registered refresh schedule specifies 80 MB. The same selected limit bounds each wire or decoded response and the cumulative retained wire and decoded bodies, with additional reserve while reading. The selected limit is recorded with capture evidence and must match for retained-capture replay. Rights, vintage, baseline, schema/ID/coverage compatibility, and release acceptance remain pending. The refresh schedule is registered as stopped.
