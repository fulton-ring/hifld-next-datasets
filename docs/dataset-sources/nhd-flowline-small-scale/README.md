# NHD Flowline - Small Scale source record

- Inventory ID: `nhd/flowline-small-scale-2` (issue #221). No pipeline is implemented for this dataset: the exact producer publication is a retired historical release and no currently maintained agency publication recreates it. Park/retire is a supervisor decision (`needs_decision`: "no maintained source: park or retire"); the supervisor's planning note on the issue (2026-11-13) accepted the research finding and routed this card to the documentation-only park/provenance flow.
- Crosswalk match: the DHS HIFLD Open crosswalk (DOI 10.3886/E241367V1) resolves to `www.datalumos.org` (DataLumos/ICPSR is a banned fetch host under the source policy), so it was not downloaded; the mapping was verified directly against the producing agency's live services. The HIFLD inventory description for this row is the USGS NHD service description verbatim (NHD/GNIS gazetteer text, "Data Refreshed March, 2025" in the archive snapshot) with agency "US Geological Survey"; the inventory Download Location is the DataLumos project 240274 third-party mirror, which was never fetched.
- Exact producer publication (identified, not used as a pipeline input): USGS NHD MapServer layer 4 "Flowline - Small Scale", `https://hydro.nationalmap.gov/arcgis/rest/services/nhd/MapServer/4` — polyline layer, served Web Mercator (102100/3857, `hasZ`/`hasM` true), anonymous REST, maxRecordCount 2000, ArcGIS Server currentVersion 11.3. The service also hosts the territories sibling layer 5 "Flowline - Small Scale (HI, PR, VI, Pacific Territories)" (a separate inventory entry, #222) and layer 6 "Flowline - Large Scale" (NHD high resolution, #220). Live checks 2026-11-13: 2,691,353 features (`returnCountOnly`); every feature carries `RESOLUTION` "Medium" (1:100,000 medium-resolution NHD; live group-by count 2,691,353 in one "Medium" group); 132 fields — the legacy NHD flowline schema (OBJECTID, FDATE, GNIS_ID, GNIS_NAME, LENGTHKM, REACHCODE, FCODE, FTYPE, RESOLUTION, FLOWDIR, WBAREACOMI) plus the complete NHDPlus V2 value-added attribute suite (COMID, StreamLeve/StreamOrde/StreamCalc, FromNode/ToNode, Hydroseq, LevelPathI, Pathlength, TerminalPa, ArbolateSu, Divergence, StartFlag/TerminalFl, DnLevel/UpLevelPat/UpHydroseq/DnLevelPat/DnMinorHyd/DnDrainCou/DnHydroseq, FromMeas/ToMeas, RtnDiv, VPUIn/VPUOut, AreaSqKM, TotDASqKM/DivDASqKM, elevation/slope fields, per-VPU QA/VA/QC/VC/QE/VE_MA and QA_01..QA_12 columns, RPUID, VPUID) and `Enabled`/`keep_gaz_string` bookkeeping; sampled rows: FTYPE "ArtificialPath", FCode 55800, COMID 721640, REACHCODE "01010002000001", FDATE epoch 1219881600000 (2008-08-28). Service copyright reads "USGS TNM – National Hydrography Dataset.  Data Refreshed October, 2026."
- Retirement evidence (checked 2026-11-13): USGS states "As of October 1, 2023, the NHD was retired. NHD data will continue to be available, but no longer maintained. The most current data will be available through the 3D Hydrography Program (3DHP)" (https://www.usgs.gov/national-hydrography/national-hydrography-dataset); the 3DHP products page classifies the legacy NHD services and downloads as "no longer updated and maintained" and provided "for reference purposes" (https://www.usgs.gov/3d-hydrography-program/access-3dhp-data-products). The October 2026 "Data Refreshed" line is periodic republication of the same static legacy content, not data stewardship (HIFLD's own snapshot recorded "Data Refreshed January, 2024" for the same service). A prior independent review in this dataset family (#806) ruled the retired reference publication unacceptable as a pipeline source.
- Maintained-successor check (checked 2026-11-13): the USGS 3DHP_all FeatureServer (`https://3dhp.nationalmap.gov/arcgis/rest/services/usgs_3dhp_all/FeatureServer`, national "Flowline" layer 50, 30,251,533 features, quarterly updates, tracked as its own inventory entry `nhd/flowline`, issue #219, merged pipeline #816) is the maintained successor product, but it is elevation-derived hydrography carrying a different data model (`id3dhp`, `featuredate`, `mainstemid`, `gnisid`, `hydrosequence`, ...; no `RESOLUTION`, no NHDPlus COMID/Hydroseq/LevelPathI VAA suite) and does not recreate the 1:100,000 medium-resolution flowline product at its cartographic scale or schema. NHDPlus HR covers high-resolution content for CONUS/HI/territories and only portions of Alaska. No currently published, maintained dataset recreates the medium-resolution flowlines.
- EPA NHDPlusV2 check (checked 2026-11-13): the 1:100k medium-resolution NHD's last content suite is NHDPlus Version 2 (EPA custodian; `https://www.epa.gov/waterdata/nhdplus-national-data`; NHDPlusV2.1 user guide dated 2019-03-13; V2 content built from the 2012 NHD medium-resolution snapshot; national file set last changed 2022-08-23 with updates ceased 2011). Frozen historical build; not a currently maintained publication.
- Mirror policy: the DataLumos/ICPSR archive entry cited by the issue is a third-party mirror and was never fetched; no archive or mirror is a pipeline candidate.
- Audit trail: no ingest, catalog or publish assets exist for this dataset and none were created; this file is the only change this issue contributes to `main` pending the supervisor decision (consistent with the sibling source records for #232/#217 and the research disposition already posted on this issue).
