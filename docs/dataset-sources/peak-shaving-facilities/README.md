# Peak Shaving Facilities source finding

The inventory identifies DOE/ORNL as publisher, but the DataLumos historical archive and DHS crosswalk could not be inspected in this run because both returned HTTP 403 challenge pages. ArcGIS Online search found a public HIFLD-labelled item owned by `HSEMA_PPD`; its description says it is HIFLD data, while its saved FeatureServer URL now returns HTTP 400 `Invalid URL`. This is historical mirror evidence, not a maintained DOE/ORNL feed.

A similarly titled `US Peak Shaving Facilities` service is published by `maps_ft`, a third-party ArcGIS account. Its description counts 60 peak-shaver and 41 satellite facilities but does not identify a DOE/ORNL delegation or a source release. It remains a separately labelled fallback candidate and is not suitable for a source adapter without lineage evidence.

PHMSA does publish maintained, monthly updated LNG annual-report tables. The current bulk ZIP is 2.36 MB and its 2025 Part B table has 309 reported facility rows, including 70 classified `Peak Shaving` and 32 `Satellite`. The table provides LNG facility IDs, names, status and state/ZIP, but has no coordinates, street addresses or city. PHMSA's 2026 proposal says it is considering adding latitude/longitude in a future annual form; PHMSA's public NPMS source remains restricted and exposes only county summaries to the public. The table also does not cover propane-air facilities in the inventory's HIFLD definition.

FERC's current jurisdictional peakshaver list is an even narrower subset: 12 existing sites, one under construction and one proposed, named with city/state and shown on a map without an exact coordinate table. Neither FERC nor PHMSA alone establishes the complete HIFLD/ORNL target population or point locations. The current records offer useful LNG facility IDs/classifications, but cannot create the target geometry without substituting coordinates or omitting the propane population.

No maintained exact DOE/ORNL source, release date, exact historical match, complete extraction, or schema/ID contract is established. Do not build an archive-refresh pipeline from these partial records or third-party copies. Reopen source research if DOE/ORNL provides authoritative location data or confirms a maintained source and its relationship to this inventory entry.
