# Distance Marks (USACE IENC)

The draft source is the USACE Inland Electronic Navigational Charts `DISTANCE_MARK_POINT` ArcGIS layer, service layer 10: <https://ienccloud.us/arcgis/rest/services/IENC_Feature_Classes/DISTANCE_MARK_POINT/MapServer/10>. The public IENC feature-class directory lists this service; the layer metadata reports `copyrightText` as `USACE IENC`, point geometry, and EPSG:4326. It describes distance marks as measures from an origin, usually on canals. This records the service attribution and does not establish any broader publisher delegation or rights decision.

The observed layer has 7,453 records, an `OBJECTID` roster, and ten non-geometry source fields: `Category_of_Distance_Mark`, `Horizontal_Units`, `Waterway_Distance`, `Information`, `Scale_Minimum`, `Source_Date`, `Source_Indication`, `Source_Dataset`, and `Feature_ID`. The pipeline retains each field and its source value, exact native XY, request body/wire bytes, receipts, and before/after count and ID snapshots. It quarantines count, ID, schema, CRS, dimensions, pagination, or transfer-limit drift. Default refreshes make a fresh source snapshot. An explicit `retained_source_version` config supports evidence-only reprocessing of an existing capture without network access; it does not serve as a cache hit or establish currentness.

This scope is the complete observed IENC service layer, whose chart coverage is inland and regional. It does not demonstrate equivalence to the archived HIFLD record, current nationwide distance-mark coverage, or the complete IENC master geodatabase. The HIFLD inventory labels its DataLumos V1 item as modified 2025-04-08; that archive timestamp is not an IENC source edition date. Exact crosswalk matching and historic continuity remain unverified. Source, schema/ID contract, coverage, rights, and release acceptance remain false; the scheduled refresh is stopped.
