# Distance Marks (USACE IENC)

The draft source is the USACE Inland Electronic Navigational Charts `DISTANCE_MARK_POINT` ArcGIS layer, service layer 10: <https://ienccloud.us/arcgis/rest/services/IENC_Feature_Classes/DISTANCE_MARK_POINT/MapServer/10>. The public IENC feature-class directory lists this service; the layer metadata reports `copyrightText` as `USACE IENC`, point geometry, and EPSG:4326. It describes distance marks as measures from an origin, usually on canals.

Official distribution is documented by the public USDOT BTS NTAD item [`7ec34864c8804468a9cf52d437fe4b6c`](https://www.arcgis.com/sharing/rest/content/items/7ec34864c8804468a9cf52d437fe4b6c?f=json) (owner `USDOT_BTS`, type PDF, verified live 2026-11-10): its record names the Inland Electronic Navigational Charts program and explicitly links the official `IENC_Feature_Classes` service directory and the `USACE_IENC_Master_Service_gdb.zip` master file geodatabase. Every fresh capture and retained replay now validates this BTS item first (identity, access, and all three delegation markers) plus the service directory (`IENC_Feature_Classes/DISTANCE_MARK_POINT` MapServer), the service document (`mapName` `DISTANCE_MARK_POINT`, `copyrightText` `USACE IENC`, exactly one advertised layer id 10 of point geometry) before and after extraction, and quarantines on any drift. No BTS item succession or historical HIFLD equivalence is claimed; rights decisions remain pending.

Live re-verification on 2026-11-10 (bounded anonymous metadata/count/ID probes): directory, service, and layer identity unchanged; count 7,453; complete unique `OBJECTID` roster exactly 1–7453 with roster SHA-256 `6e54039c7e61cbf1abd27cd8bcb45e3a447f1cb8ef25cd7f81815263596b26b9`; ten-field schema unchanged; layer extent `(-96.66343689999997, 29.732981300000063, -79.48022249999997, 45.142035400000054)` EPSG:4326. The exact ID roster, roster digest, and layer extent are now pinned fail-closed.

The observed layer has 7,453 records, an `OBJECTID` roster, and ten non-geometry source fields: `Category_of_Distance_Mark`, `Horizontal_Units`, `Waterway_Distance`, `Information`, `Scale_Minimum`, `Source_Date`, `Source_Indication`, `Source_Dataset`, and `Feature_ID`. The pipeline retains each field and its source value, exact native XY, request body/wire bytes, receipts, and before/after count and ID snapshots. It quarantines count, ID, schema, CRS, dimensions, pagination, or transfer-limit drift. Default refreshes make a fresh source snapshot. An explicit `retained_source_version` config supports evidence-only reprocessing of an existing capture without network access; it does not serve as a cache hit or establish currentness. Retained captures taken before the BTS delegation chain was added cannot be replayed; the replay refuses a capture whose `bts_item` evidence is missing.

This scope is the complete observed IENC service layer, whose chart coverage is inland and regional. It does not demonstrate equivalence to the archived HIFLD record, current nationwide distance-mark coverage, or the complete IENC master geodatabase. The HIFLD inventory labels its DataLumos V1 item as modified 2025-04-08; that archive timestamp is not an IENC source edition date. Exact crosswalk matching and historic continuity remain unverified. Source, schema/ID contract, coverage, rights, and release acceptance remain false; the scheduled refresh is stopped.
