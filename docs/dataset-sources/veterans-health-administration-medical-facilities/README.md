- Exact producer publication (identified, not used as a pipeline input): the VA Facilities API v1, production base `https://api.va.gov/services/va_facilities/v1`, published by the Department of Veterans Affairs (Lighthouse) and documented at `https://developer.va.gov/explore/api/va-facilities`. Live checks 2026-11-14:
  - **Key-gated**: `GET /facilities?per_page=1` without credentials answers HTTP 401 `{"message":"No API key found in request"}`; `/ids` and `/facilities/all` answer HTTP 401; the sandbox host `sandbox-api.va.gov` is equally key-gated and serves only test data. Obtaining a key requires registering at developer.va.gov ("third party seeking access ... will need to complete a quick application to obtain an API key", per the VA `vets-api-clients` README) — an access grant the factory cannot self-obtain.
  - **Publicly verifiable contract without a key**: the production OpenAPI document `https://api.va.gov/internal/docs/facilities/v1/openapi.json` is anonymously readable (HTTP 200, title "VA Facilities", version 1.0.0). Facility IDs are `prefix_stationNumber` (e.g. `vha_402GA`, `vc_0872MVC`) — the same VAST station-number scheme the HIFLD layer's `STA_NO` uses (3-character parents, 5-character CBOC/support sites, 7-character satellites). Health facilities carry `facilityType: va_health_facility` with `lat`/`long`, addresses, `visn`, hours and services.
  - **Scope is materially different from the HIFLD layer**: the API returns *active* facilities of all administrations (health `vha`, benefits `vba`, cemeteries `nca`, vet centers `vc`), includes mobile facilities with an explicit "latitude/longitude and address could be inaccurate" warning, and drops null fields from responses; the HIFLD layer covered only VHA sites (VA hospitals, RRTP, NHCU, outpatient clinics, Vet Centers, VAMC), excluded planned/suspended non-operational sites and mobile clinics, and carried NGA-requested text normalisation. A rebuild on the API therefore needs a maintainer compatibility/changed-scope decision in addition to the key grant. Release notes (`https://developer.va.gov/explore/api/va-facilities/release-notes`): v1 launched 2023-08-24; v0 deprecated 2024-01-01 and deactivated 2024-06-17 (production v0 routes now answer HTTP 404, verified live); `/facilities` page size max 1000. data.gov lists "VA Facilities API" as a Department of Veterans Affairs dataset with catalog update 2026-08-11 (catalog.data.gov API is proxied-404 from the factory pod; listing read via third-party index).
