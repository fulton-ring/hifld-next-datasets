# Lateral Buoys (USACE IENC)

The draft reads the complete `LATERAL_BUOY_POINT` layer (MapServer layer 15) from USACE's official IENC `IENC_Feature_Classes` service at `https://ienccloud.us/arcgis/rest/services/IENC_Feature_Classes/LATERAL_BUOY_POINT/MapServer`. Service metadata declares copyright "USACE IENC"; the BTS NTAD IENC catalog item (`7ec34864c8804468a9cf52d437fe4b6c`, owner `USDOT_BTS`) explicitly links this service and the master file geodatabase, which is retained as delegation/distribution evidence.

Coverage observation requiring a maintainer decision: at the dated 2026-10-22 capture the official live layer held only 10 features (`OBJECTID` 1–10) across the upper Mississippi/Ohio/Illinois/Arkansas rivers. The historical HIFLD Open item (DataLumos project 239484 V1, inventory date_issued 2018-02-21) described a much larger lateral-buoy population, and USACE now maintains most operational lateral marks in the separate weekly-updated `USACE_Buoys_Service` (3UABUOYS layer, ingested separately as `dynamic-buoys-usace-ienc-`). The live static layer is therefore treated as the current producer publication of this inventory entry — not an archive substitute — but historical equivalence and coverage acceptance remain explicitly unaccepted.

The candidate preserves all 14 declared ArcGIS fields (including `OBJECTID`, `Feature_ID`, `Source_Date` as declared strings, and `Scale_Minimum` as integer), the native EPSG:4326 point coordinates without reprojection, and complete decoded/wire response bodies with checksummed receipts. Count and before/after ID roster checks, per-page attribute/geometry type checks, and quarantine of incomplete captures guard drift. The DataLumos archive page itself was not treated as a maintained feed and was not fetched for byte comparison.

HIFLD historical comparison baseline, source release date, schema/ID contract approval, coverage equivalence, rights, and release acceptance remain pending. The ingest asset and its recurring refresh stay unapproved/stopped, and the candidate is marked `approved: false` end to end.
