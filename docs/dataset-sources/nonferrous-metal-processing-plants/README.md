# Nonferrous Metal Processing Plants — parked: no maintained USGS producer publication

Assigned dataset: USGS National Atlas *Nonferrous Metal Processing Plants* layer (`minop7x020`, publication 200512, Minerals Information Team operations active in 2003), identified by the surviving USGS legacy FGDC metadata at https://thor-f5.er.usgs.gov/ngtoc/metadata/waf/atlas_legacy/minop7x020.xml (20,018 bytes, SHA-256 `1ff2b2c8910aca0fe86e3241c0c3c3e1c45a24c396c4401c074c110a98b7c9ee`, metadata date 20060713, process date 200511). Producer scope pinned from that document: 71 entity points; identifier `Minop7x020` 1..71; `Plant_min` domain M/P (mine and plant) and P (plant); commodity classes Aluminum, Antimony, Beryllium, Cadmium, Copper, Gold, Iron, Lead, Magnesium metal, Rhenium, Selenium, Silver, Strontium, Titanium metal, Zinc; declared latitude range 27.883..48.847 and longitude range -122.706..-71.299; NAD 1983.

## Why the dataset is parked (dated evidence)

- **Original producer release retired.** `http://dds.cr.usgs.gov/pub/data/nationalatlas/minop7x020_nt00024.tar.gz` (named by the surviving FGDC `onlink`) returns HTTPS 404 on the live USGS endpoint (observed 2026-11-13; the http URL 301-redirects to the https 404). The inventoried DataLumos project 240272 V1 is a banned archive source and was never fetched. No third-party mirror was used.
- **Producer survey publication is a one-time release, not a maintained successor.** The USGS-owned `https://mrdata.usgs.gov/mineplant/mineplant.zip` — *Active Mines and Mineral Processing Plants in the United States in 2003* (National Minerals Information Center; FGDC publication 2005; 513,191 bytes, SHA-256 `6dabd3bbedcb1fbf0c5155fb349228951a9b2cbd065311484eb479c25997ee4e`) and its FGDC metadata `https://mrdata.usgs.gov/metadata/mineplant.xml` (26,366 bytes, SHA-256 `419629edaf825f2d55ed1dd03fe3a9921d0d35a8240c208b44b53d30c8b9ead0`, metadata date 20201230) declare **progress "Complete"** and **update frequency "None planned"** with ground condition 2003 (verified by anonymous retrievals on 2026-11-13 matching the pinned digests). Under the current source policy a one-time release with no planned refresh is not a pipeline input; live agency hosting and a 2020 metadata date do not establish maintenance. The same adjudication was made for the sibling Nonferrous Metal Mines layer in PR #825.
- **Current producer alternatives checked (2026-11-13):**
  - *Mines, smelters, refineries, and recycling facilities in the United States* (USGS NMIC, DOI 10.5066/P1BUPUAM, ScienceBase item 6a3edaf71ba49b7c2e263528, published 20260629, data period 20241204..20260430): a current tabular worksheet (56 columns; Feature Type taxonomy; Level 1–5 commodity taxonomy) that publishes **no coordinate columns** — location is "Location Description" (town/state text) and "First-Level Administrative Division" (state) — so it cannot recreate this entity-point layer; its own FGDC metadata also declares progress Complete and update None planned.
  - *ScienceBase catalog search for maintained nonferrous processing-plant point products* (2026-11-13): the producer catalog returns only the 2003 mineplant survey item and its 2010 BLM REA derivative copies; no maintained nonferrous processing-plant point publication exists.
  - *Mineral Resource Data System (MRDS)* (mrdata.usgs.gov/mrds/): dated prior project research (2026-11-12) — updates ceased and the product is a materially different global deposit database, not a maintained publication of active US operations.
  - *USMIN mineral deposit areas* (mrdata.usgs.gov/deposit/): dated prior project research (2026-11-12) — developing critical-minerals product, different scope.

No maintained USGS producer publication capable of reconstructing this layer is known, so per the current source policy the dataset is parked. `src/dagster_hifld/sources/nonferrous_metal_processing_plants.py` keeps only the pinned producer-contract facts and the fail-closed refusal (`no_maintained_producer_publication_park_or_retire`); it defines no fetching, decoding, staging or candidate output, and every materialization attempt fails closed. The registered ingest asset fails closed and the monthly schedule is STOPPED.

## Resuming requires an explicit maintainer decision

One of: park permanently; retire the dataset; accept an explicitly provided preserved capture of the original producer archive (the ferrous-siblings route, with capture provenance outside banned hosts); or name a maintained producer source. If USGS ever publishes a different release status for the mineplant metadata document, `parse_mineplant_release_status` fails closed with a re-evaluation error instead of absorbing the change.

## Research context retained (comparison only, never inputs)

The existing published HIFLD v1 object of this dataset at `https://storage.googleapis.com/hifld-next-datasets-prod/hifld/nonferrous-metal-processing-plants/nonferrous-metal-processing-plants/v1.0.0/geoparquet/nonferrous-metal-processing-plants.parquet` (19,356 bytes, SHA-256 `959ef55591f936aaec5e65b6428feae3220c2883dbf0c5b4ea807ec37c30a7b4`) was compared during the 2026-11-13 research capture: 71 rows with `MINOP7X020` 1..71 (all unique), `Plant_min` P=45 and M/P=26, and all 15 producer-declared commodity classes present — matching the producer-declared 71 entity points. All 71 published LATITUDE/LONGITUDE pairs (3-decimal) exactly match plant rows of the producer's mineplant survey publication, and the mineplant plant rows in the 15 commodity classes number exactly 71 with the same P=45/M/P=26 split; but mineplant carries its own `id` numbering and 5-decimal coordinates, so no approved cross-package ID/coordinate mapping exists, and mineplant remains a frozen one-time release. These facts informed the park decision; no candidate was published and `approved: false` applies throughout.

No production write, schedule start, or release acceptance is implied.
