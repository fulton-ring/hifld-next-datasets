# Obstruction Locations (USACE IENC)

The draft source is the USACE Inland Electronic Navigational Charts `OBSTRUCTION_POINT` ArcGIS layer, service layer 19: <https://ienccloud.us/arcgis/rest/services/IENC_Feature_Classes/OBSTRUCTION_POINT/MapServer/19>. The public IENC feature-class directory lists this service; the layer metadata reports `copyrightText` as `USACE IENC`, point geometry, EPSG:4326, and a 2,000-record transfer limit.

Official distribution is documented by the public USDOT BTS NTAD item [`7ec34864c8804468a9cf52d437fe4b6c`](https://www.arcgis.com/sharing/rest/content/items/7ec34864c8804468a9cf52d437fe4b6c?f=json) (owner `USDOT_BTS`, type PDF, verified live 2026-11-11): its record names the Inland Electronic Navigational Charts program and explicitly links the official `IENC_Feature_Classes` service directory and the `USACE_IENC_Master_Service_gdb.zip` master file geodatabase. Every production capture validates this BTS item first (identity, access, and all three delegation markers) plus the service directory (`IENC_Feature_Classes/OBSTRUCTION_POINT` MapServer) and the service document (`mapName` `OBSTRUCTION_POINT`, `copyrightText` `USACE IENC`, exactly one advertised layer id 19 of point geometry) before and after extraction, and quarantines on any drift. No BTS item succession or historical HIFLD equivalence is claimed; rights decisions remain pending.

Live verification on 2026-11-11 (bounded anonymous metadata/count/ID/full-page probes): count 150; complete unique `OBJECTID` roster exactly 1–150 with roster SHA-256 `3a46161d49b5d5dd4c791d4797d488691a68683b72d983b1b2ced6624f534139`; fifteen-field schema (OID, geometry, twelve strings of length 254, one integer); declared layer extent `(-95.41964149999995, 29.745652300000074, -80.43407549999995, 44.202593000000036)` EPSG:4326 with the observed feature envelope inside it; all 150 features returned by one bounded page with XY-only point geometry. The ID roster, roster digest, full field declarations, and layer extent are pinned fail-closed.

The observed layer has 150 records and fourteen non-geometry source fields: `Category_of_Obstruction`, `Value_of_Sounding`, `Water_Level`, `Natural_Surface`, `Object_Name`, `Information`, `Scale_Minimum`, `Source_Date`, `Source_Indication`, `Source_Dataset`, `Nature_of_Construction`, `Exposition_of_Sounding`, and `Feature_ID`. The pipeline retains each field and its source value verbatim (including empty strings), the exact native XY of every point, request body/wire bytes, checksummed receipts, and before/after service/layer/count/ID snapshots. It rejects count, ID-roster, schema, attribute-type, CRS (layer, page, and per-feature declarations), dimension, or transfer-limit drift, and quarantines failed captures with their retained evidence. A re-capture of identical validated source bytes reuses the first sealed candidate and provenance; changed raw bytes produce a distinct candidate version. `Source_Date` attribute values (20020911–20260722) are per-record source dates and do not establish a layer release date.

This scope is the complete observed IENC service layer, whose chart coverage is inland and regional. It does not demonstrate equivalence to the archived HIFLD record (the DataLumos V1 item's 2025-04-08 modification stamp is not an IENC source edition date), current nationwide obstruction coverage, or the complete IENC master geodatabase. Exact crosswalk matching and historic continuity remain unverified; the October 2026 coordinator-era comparison against the published HIFLD GeoParquet release found 145 historical rows against these 150 with only partial geometry/ID overlap, and it remains exploratory. Source, baseline, schema/ID contract, coverage, rights, and release acceptance remain false; the scheduled refresh is stopped.
