# Administrative Areas (USACE IENC): blocked source decision

No faithful, current USACE producer source is established. The candidate ArcGIS item ([master item](https://www.arcgis.com/home/item.html?id=6ee858a220a143a48c8d40a6cf0d3680); [layer 56 query](https://services7.arcgis.com/n1YM8pTrFmm7L4hs/arcgis/rest/services/USACE_IENC_Master_Service/FeatureServer/56/query)) returns a complete 2,966-feature set, but USACE delegation, source terms, actual release date and the exact [DHS crosswalk](https://doi.org/10.3886/E241367V1) match remain unverified. The old `/ADMINISTRATIVE_AREA/MapServer/0` endpoint returns ArcGIS 404. Agency and DataLumos requests returned provider HTTP 403; this does not establish a maintained replacement.

The [PASDA ZIP](https://www.pasda.psu.edu/download/hifld_fema/conus_clipped/Administrative_Areas__USACE_IENC_.zip) and [DataLumos archive](https://www.datalumos.org/datalumos/project/238556/version/V1/view) are fallback/archive candidates, not verified current agency feeds. The pinned [published v1.0.0 candidate](https://storage.googleapis.com/hifld-next-datasets-prod/hifld/administrative-areas-usace-ienc/administrative-areas-usace-ienc/v1.0.0/geoparquet/administrative-areas-usace-ienc.parquet) is unapproved: it has 3,131 features versus 2,966 at the service; `Feature_ID` is absent from the published schema, published `id` is unmapped, and 532 attribute values differ across 302 `OBJECTID` joins. Diagnostic geometry matching does not approve a tolerance or continuity claim: 2,757 matches leave 209 source and 374 published geometries unmatched. No source, ID/schema mapping, baseline, coverage migration or release decision is accepted. Keep **Blocked / Potential breaking change / Needs decision**.

Prior evidence: [source research](https://github.com/fulton-ring/hifld-next-datasets/issues/6#issuecomment-6259964952), [independent research review](https://github.com/fulton-ring/hifld-next-datasets/issues/6#issuecomment-6259999474), [PR progress](https://github.com/fulton-ring/hifld-next-datasets/pull/423#issuecomment-6259965182) and [PR review](https://github.com/fulton-ring/hifld-next-datasets/pull/423#issuecomment-6259999640). Shared promotion work remains in [#417](https://github.com/fulton-ring/hifld-next-datasets/issues/417); it does not clear this source blocker.
