# Nonferrous Metal Mines — parked: no maintained USGS producer publication

Assigned dataset: USGS National Atlas *Nonferrous Metal Mines* layer (`minop6x020`, publication 200512, Minerals Information Team operations active in 2003), identified by the surviving USGS legacy FGDC metadata at https://thor-f5.er.usgs.gov/ngtoc/metadata/waf/atlas_legacy/minop6x020.xml (18,443 bytes, SHA-256 `663509feaae108d27fbe98818384adf5cb23d122f3a0cb069af7ce25f031218a`, metadata date 20060713). Producer scope pinned from that document: 123 entity points; identifier `Minop6x020` 1..123; `Plant_min` domain M (mine) and M/P (mine and plant); commodity classes Beryllium, Copper, Germanium, Gold, Lead, Silver, Zinc (ferrous classes Iron, Cobalt, Molybdenum, Nickel, Rhenium excluded); declared latitude range 31.429..68.070 and longitude range -162.865..-83.407.

## Why the dataset is parked (dated evidence)

- **Original producer release retired.** `http://dds.cr.usgs.gov/pub/data/nationalatlas/minop6x020_nt00023.tar.gz` (named by the surviving FGDC `onlink`) returns 404 on the live USGS endpoint (observed 2026-11-13; earlier checks in this PR agree). The inventoried DataLumos project 240271 V1 is a banned archive source and was never fetched. No third-party mirror was used.
- **Producer survey publication is a one-time release, not a maintained successor.** The USGS-owned `https://mrdata.usgs.gov/mineplant/mineplant.zip` — *Active Mines and Mineral Processing Plants in the United States in 2003* (National Minerals Information Center; FGDC publication 2005; 513,191 bytes, SHA-256 `6dabd3bbedcb1fbf0c5155fb349228951a9b2cbd065311484eb479c25997ee4e`) and its FGDC metadata `https://mrdata.usgs.gov/metadata/mineplant.xml` (26,366 bytes, SHA-256 `419629edaf825f2d55ed1dd03fe3a9921d0d35a8240c208b44b53d30c8b9ead0`, metadata date 20201230) declare **progress "Complete"** and **update frequency "None planned"** with ground condition 2003 (verified by independent anonymous retrievals on 2026-11-13 matching the pinned digest). Under the current source policy a one-time release with no planned refresh is not a pipeline input; live agency hosting and a 2020 metadata date do not establish maintenance. An earlier revision of this PR described this product as a "maintained successor"; that claim is withdrawn.
- **Current producer alternatives checked (2026-11-13):**
  - *Mines, smelters, refineries, and recycling facilities in the United States* (USGS NMIC, DOI 10.5066/P1BUPUAM, ScienceBase item 6a3edaf71ba49b7c2e263528, published 20260629, data period 20241204..20260430, CC0): a current tabular worksheet (1,289 US rows; Feature Type "Mines and Quarries"/"Mineral Processing Plant"; Level 1–5 commodity taxonomy) that publishes **no coordinate columns** — location is "Location Description" (town/state text) and "First-Level Administrative Division" (state) — so it cannot recreate this entity-point layer; its own FGDC metadata also declares progress Complete and update None planned.
  - *Mineral Resource Data System (MRDS)* (mrdata.usgs.gov/mrds/): dated prior project research (2026-11-12) — updates ceased and the product is a materially different global deposit database, not a maintained publication of active US operations.
  - *USMIN mineral deposit areas* (mrdata.usgs.gov/deposit/): dated prior project research (2026-11-12) — developing critical-minerals product, different scope.

No maintained USGS producer publication capable of reconstructing this layer is known, so per the current source policy the dataset is parked. `src/dagster_hifld/sources/nonferrous_metal_mines.py` keeps only the pinned producer-contract facts and the fail-closed refusal (`no_maintained_producer_publication_park_or_retire`); it defines no fetching, decoding, staging or candidate output, and every materialization attempt fails closed. The registered ingest asset fails closed and the monthly schedule is STOPPED.

## Resuming requires an explicit maintainer decision

One of: park permanently; retire the dataset; accept an explicitly provided preserved capture of the original producer archive (the ferrous-siblings route, with capture provenance outside banned hosts); or name a maintained producer source. If USGS ever publishes a different release status for the mineplant metadata document, `parse_mineplant_release_status` fails closed with a re-evaluation error instead of absorbing the change.

## Research context retained (comparison only, never inputs)

The existing published HIFLD v1 objects of this dataset at `https://storage.googleapis.com/hifld-next-datasets-prod/hifld/nonferrous-metal-mines/nonferrous-metal-mines/v1.0.0/` (geoparquet 21,301 bytes, SHA-256 `1de4144906a419909377f307f3567bd3e42a23460e04739cbcc93a42925f7898`; geojson 46,876 bytes, SHA-256 `a49dbed8cf33a3d53c854df47a19031d399f36392c6e686eedfc2bbcc7ea8056`) were compared during the 2026-11-13 research capture: 136 operations with HIFLD's own `MINERAL_OPERATIONS_ID` 1..136 (no approved cross-package mapping); all 136 are present in the seven-commodity mineplant rows; 13 published rows are processing-only facilities (Plant_min P) outside the producer mines scope; 5 mineplant processing-only operations (White Pine Copper Refinery; Johnson Matthey Salt Lake City under Gold and Silver; Herculaneum Smelter; Clarksville) have no published row. LATITUDE/LONGITUDE values are numerically identical in both USGS products; the contradictory datum claims (mineplant PRJ NAD 1927, legacy FGDC NAD 1983) were retained unresolved and no transformation was applied. These facts informed the park decision; no candidate was published and `approved: false` applies throughout.

No production write, schedule start, or release acceptance is implied.
