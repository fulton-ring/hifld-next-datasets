## Working implementation

`src/dagster_hifld/assets/fuel_stations.py` contains:

- A bounded, keyless live capture function with pre/post completeness guards, native geometry, raw byte receipts and explicit ArcGIS error/truncation detection. Three attempts retain each successful, HTTP/application-error and partial response in private quarantine before JSON validation. Every data receipt requires both the request and observed final URL to match the exact official BTS layer and query scope; missing redirect observations or extra query projections are blocked.
- A registered source-specific `bts_alternative_fueling_stations` asset with explicit capture directory and immutable semantic version. An empty capture path fetches the live official BTS feed. It permits isolated local staging only during review.
- Lossless raw staging, deterministic typed GeoParquet candidate generation, a streaming Arrow-to-GeoPackage bridge preserving all raw types/nullability/values, and identity-attribute native-CRS GeoJSON for the existing catalog/format pipeline. Epoch-ms dates stay int64, source integer IDs stay integer, strings/leading zeros remain strings. No published projection is applied.
- A pinned unapproved draft source schema signature; changed names/types/nullability stop canonical staging for review. Every layer/extent/page CRS witness is validated against native3857 and its known102100 alias; contradictory/unknown/WKT/vertical definitions stop before candidate creation. Stable service, geometry, identifier, dimension and extent metadata is compared before/after capture. Incomplete/changed source snapshots, duplicate/null identifiers, malformed geometry and immutable-version collisions fail.
- A separately materializable raw → typed-candidate graph with dynamic partitions.

All original JSON bytes remain available. The full typed GeoPackage bridge also passed all 103,502 rows/80 fields/native WKB checks. An earlier generic GeoJSON→GeoPackage experiment coerced nullable integers/ID values into floats or strings; its complete diagnostic is retained, and the source-specific Arrow bridge replaces that path. Six longitude values use integer-looking JSON tokens despite source-declared Double; candidate physical double representation follows that declaration without changing numeric value. This is explicit and is not an ID/string conversion. Dates are not converted to timestamps or historical published strings.

**Shapefile and PMTiles are explicitly unsupported for this draft.** The 80-column schema includes long identifier names and embedded JSON strings that cannot fit the DBF naming/width model without a reviewed mapping. No schema-renaming/truncation/null conversion is approved. Actual PMTiles generation also reports sequence-assigned feature IDs, and the executing converter permits density-based dropping. No rendered per-zoom ID/coverage equivalence was proved; generated tiles are retained as diagnostic evidence only. Shared #417 exclusions run before generation or existing-output reuse. Canonical typed candidate/GeoPackage/Parquet remain available as drafts, with no promotion authority.
