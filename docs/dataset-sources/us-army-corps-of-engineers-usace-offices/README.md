# USACE Offices source draft

The candidate is the public USACE ArcGIS Online `USACE Offices` FeatureServer layer 0 (item `8f5eaddf8c6046b7902ad00f14029fb8`, owner `usace_erd_jlf`). Its item description exactly matches the HIFLD inventory wording: “USACE District, Division and Research Lab Locations. This data set does not include field offices.” The service is hosted in USACE's `services7` organization. A historical HIFLD metadata PDF also lists the same `usace_offices/FeatureServer/0` URL. The fresh layer reported 68 point features and 68 unique `OBJECTID`s. USACE field-office and international-boundary layers have different coverage and are excluded.

The draft captures layer metadata, count and full ID rosters before and after the feature pages, retains each HTTP wire and decoded response with receipts, checks the exact declared field roster/widths/nullability/types and WGS84 points, and stages native GeoParquet with declared physical types. The nullable ArcGIS Blob field remains declared binary even when null. Mapping nonnull ArcGIS base64 strings to native binary is proposed and unapproved; the exact source JSON is retained unchanged. Immutable staged objects, first-construction identity, candidate READY state, and cached reuse are checked using shared repository machinery. Refresh is exposed only as a stopped schedule, with a blocking source-quality check.

The source release date, DHS/ICPSR crosswalk acceptance, and historical 240530 baseline comparison remain pending. DataLumos V1 and DOI fetches returned HTTP 403 in this environment, so no baseline equivalence or source release date is claimed. The USACE Mobile District map link that was verified resolves to a distinct International Boundary web map and does not identify this 68-feature layer. Full captures and runtime evidence belong under `/tmp/hifld-native-reconstruction/356/`; those artifacts are not committed.
