# Primary Roads

The draft pipeline captures the official 2025 U.S. Census TIGER/Line Primary Roads ZIP, preserving the complete archive and request receipts. The source contains 17,500 `S1100` LineString features in EPSG:4269 with native string fields `LINEARID`, `FULLNAME`, `RTTYP`, and `MTFCC`.

This is a proposed source route for the HIFLD inventory entry. The historical DataLumos archive and exact DHS crosswalk row remain unavailable for comparison, so historical coverage equivalence, baseline compatibility, rights, schema/ID contracts, and release acceptance remain unresolved. The annual refresh schedule is STOPPED.
