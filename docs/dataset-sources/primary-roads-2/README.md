# Primary Roads

The stopped draft refresh discovers the largest exact annual `TIGER20YY/` directory in the [producer listing](https://www2.census.gov/geo/tiger/), requires its single national Primary Roads ZIP, and preserves listing bodies and transfer receipts. An incomplete newest edition fails rather than falling back. The current source is the [2026 national archive](https://www2.census.gov/geo/tiger/TIGER2026/PRIMARYROADS/tl_2026_us_primaryroads.zip), observed in full on 2026-11-16: 38,486,503 bytes, SHA256 `ed7c8e47344d45ecf73694e92d5d105fe6955983733e3a57317c318f80a159ef`, and 17,678 features. All have `MTFCC=S1100`, valid LineString geometry, unique non-null lexical `LINEARID` identifiers, EPSG:4269, and native string fields `LINEARID`, `FULLNAME`, `RTTYP`, and `MTFCC`.

The archive transfer is bounded at 50 MB and declared expanded members at 250 MB. Native sidecars are mandatory. Current captures compare the decoded population against the independent DBF declared record count and SHX index count, verify physical record boundaries, and reject deleted DBF records, truncation, or decoder row loss. They validate schema, CRS, IDs and geometry without applying the older edition's count or bounds. The selected listing is recaptured after transfer to detect a changed annual selection or packaging listing. This is not a transactional snapshot guarantee.

Versions bind edition, complete archive bytes and packaged processing code. An unchanged observation reuses its candidate and first immutable discovery evidence; changed bytes in the same edition create a new version, leaving earlier published paths untouched. The source manifest references captured discovery inputs. Check times and HTTP modification times are not publication dates. Producer cadence remains explicitly unknown until its documentation is captured.

Metadata and complete discovery body/wire/receipt evidence are written before the Shapefile archive is exposed. A final immutable `metadata/candidate_ready.json` records object hashes after archive readback. The existing discovery sensor does not inspect that marker and excludes these content-hash draft versions; the ingest asset explicitly registers the global publish partition. The marker records construction completeness and grants no release approval.

The explicit `capture_directory` replay option retains the older 2025 receipt/hash contract (17,500 features) for supplied offline reproduction inputs, reported as `historical_pinned_reproduction` with `latest_release_discovered=false`. It makes no latest-source claim. Earlier 2025 extraction evidence in `source.json` remains historical evidence.

This is a proposed source route for the HIFLD inventory entry. The historical DataLumos archive and exact DHS crosswalk row remain unavailable for comparison, so historical coverage equivalence, baseline compatibility, rights, schema/ID contracts, and release acceptance remain unresolved. The annual refresh schedule is STOPPED.
