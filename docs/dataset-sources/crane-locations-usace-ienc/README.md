# Crane Locations (USACE IENC)

The proposed source is layer 8 (`CRANES_POINT`) of the official USACE IENC Feature Classes service. The captured service metadata reports a point layer in EPSG:4326, 148 feature IDs, and 13 declared fields including `SHAPE`. The draft keeps all 12 non-geometry attributes and native point coordinates in GeoParquet, while raw Esri JSON responses, wire bytes, and receipts are retained with the candidate.

The evidence establishes the observed contents of this IENC layer only. It does not establish a nationwide crane inventory, a source edition date or freshness, continuity with the historical HIFLD record, an accepted identifier/schema contract, usage rights, or release approval. The USDOT BTS item describes bi-monthly USACE/AGC IENC updates but does not date this layer snapshot. Those decisions remain pending; draft refresh is stopped by default and the candidate is not approved for publication.
