# NHD Area - Small Scale (HI, PR, VI, Pacific Territories) source record

- Inventory ID: `nhd/area-small-scale-hi-pr-vi-pacific-territories-2` (issue #217). No pipeline is implemented for this dataset: the exact producer publication is a retired historical release and no currently maintained agency publication recreates it. Park/retire is a supervisor decision (`needs_decision`: "no maintained source: park or retire").
- Exact producer publication (identified, not used as a pipeline input): USGS NHD MapServer layer 8 "Area - Small Scale (HI, PR, VI, Pacific Territories)", `https://hydro.nationalmap.gov/arcgis/rest/services/nhd/MapServer/8` — polygon layer, served Web Mercator (102100/3857), anonymous REST, maxRecordCount 2000. Live checks 2026-11-13: 530 features; FDate 1994-01-01..2014-12-23; sampled `Resolution` "High"; `ComID` values in the NHDPlusV2 territory range (80004xxxxx); fields OBJECTID, Shape, Permanent_, FDate, Resolution, GNIS_ID, GNIS_Name, AreaSqKm, Elevation, FTYPE, FCode, ComID, OnOffNet, PurpCode, PurpDesc, GNIS_ID_fixed, Shape_Length, Shape_Area. The HIFLD inventory description is the service description verbatim, prefixed "Please use 3DHP for updated data"; service copyright reads "USGS TNM – National Hydrography Dataset. Data Refreshed October, 2026."
- Retirement evidence (checked 2026-11-13): USGS states "As of October 1, 2023, the NHD was retired. NHD data will continue to be available, but no longer maintained" (https://www.usgs.gov/national-hydrography/national-hydrography-dataset); the 3DHP products page classifies the legacy NHD services/downloads as "no longer updated and maintained ... for reference purposes" (https://www.usgs.gov/3d-hydrography-program/access-3dhp-data-products). The October 2026 "Data Refreshed" line is republication of static legacy content, not data stewardship.
- Maintained-successor check (checked 2026-11-13): the USGS 3DHP_all FeatureServer (`https://3dhp.nationalmap.gov/arcgis/rest/services/usgs_3dhp_all/FeatureServer`, data refreshed 2026-09-04) publishes only HydroLocation, Flowline, Waterbody, Catchment and Spatial Metadata layers — no NHD-style Area feature class; the 3DHP FY26 staged downloadable product covers Alaska and CONUS only (no HI/PR/VI/Pacific territories). 3DHP is tracked as its own inventory entry.
- EPA NHDPlusV2 check (checked 2026-11-13): territory VPUs exist (HI 20, PR/VI 21, American Samoa/Guam/CNMI 22AS/22GU/22MP) with NHDSnapshot shapefile components under `https://dmap-data-commons-ow.s3.amazonaws.com/NHDPlusV21/Data/` (EPA pages: `https://www.epa.gov/waterdata/nhdplus-hawaii-data-vector-processing-unit-20`, `.../nhdplus-puerto-rico-us-virgin-islands-data-vector-processing-unit-21`), but the territory content is a frozen historical build: initial release 12/30/2014 from a 2014 high-resolution NHD extract (NHDPlusV2 User Guide, 2019-03-13, footnote 1); last content updates 11/18/2015 (HI and PR/VI NHDSnapshot) and 05/10/2016 (PR/VI WBD pointers); nothing since. The NHD ingredient itself was retired by USGS in 2023.
- Mirror policy: the DataLumos/ICPSR archive entry cited by the issue is a third-party mirror and was never fetched; no archive or mirror is a pipeline candidate.
- Audit trail: a draft ingest of the retired layer was previously built on this issue (PR #813 head `e6cb7bd664866d1012df954692f1bea2e4449229`) and withdrawn from the merge path under the source policy after independent review; that head is research context only and was never merged.
