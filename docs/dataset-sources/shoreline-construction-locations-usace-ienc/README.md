# Shoreline Construction Locations (USACE IENC)

The draft source is the `SHORELINE_CONSTRUCTION_POINT` point layer (ID 23) in the USACE IENC Feature Classes MapServer. Its complete directly observed layer contained 4719 features in EPSG:4326 within the inland chart extent recorded in the retained source audit. The service describes the features as a fixed (not afloat) artificial structure between the water and the land, i.e. a man-made coastline. This is a regional chart-service layer, not a nationwide shoreline-construction inventory.

The source captures all native attributes and `OBJECTID` values, XY point coordinates in bounded 250-ID pages, count and ID snapshots before and after paging, and response bodies, wire bodies, and request receipts. Candidate generation retains the source CRS and coordinates without reprojection or geometry repair; the XY-only layer contract fails closed on flagged or unflagged Z/M ordinates. The observed layer may contain duplicate `Feature_ID` values, which are preserved rather than deduplicated. GeoParquet is the only candidate format; no display or lossy output policy is accepted.

USDOT BTS's current public IENC PDF item links the USACE Feature Classes service and master geodatabase; the earlier BTS map-service item returns anonymous-access denial, so catalog succession remains unverified. The historical HIFLD inventory row and its DataLumos archive (project 240649) and the DHS crosswalk DOI (10.3886/E241367V1) all return HTTP 403 anonymously, so the archive crosswalk row and historical continuity remain unverified. Rights, source acceptance, baseline comparison, schema/ID/coverage contracts, and release approval remain false. The registered refresh schedule is stopped.
