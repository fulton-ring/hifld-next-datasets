The inventory card's archive and crosswalk did not load during the 2026-10-20 check: both returned HTTP 403 challenge pages. The public USGS ArcGIS item is a strong official-source match for the title and exposes layer `PADUS4_1ManagerName`. Its item metadata cites the 2025 USGS PAD-US 4.1 release DOI, but does not establish that this version is the exact HIFLD historical baseline or an accepted successor.

The layer contains 655,335 polygon features and 37 source fields. It supports pagination with a 2,000-record limit. A 100-feature geometry response was 1,645,553 bytes; a 2,000-feature response was approximately 64 MB. A roughly 21 GB complete response is a simple page-size extrapolation only, not a measured size or a proven storage requirement. The official ScienceBase item and downloadable files could not be inspected because direct item JSON and file requests returned HTTP 403. The ArcGIS item lists no downloadable resources and its service exposes Query only. No alternate package has been established, and none is claimed absent. Metadata, count, full OBJECTID list, and a 100-feature sample were captured outside Git during the observed check. Their SHA-256 values are in `source.json` where recorded; no claim of complete raw-data preservation or freshness is made.
