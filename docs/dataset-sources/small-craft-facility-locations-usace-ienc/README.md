# Small Craft Facility Locations (USACE IENC)

The draft source is the `SMALL_CRAFT_FACILITY_POINT` point layer (ID 24) in the USACE IENC Feature Classes MapServer. Its complete directly observed layer contained 153 features in EPSG:4326 within the inland chart extent recorded in the retained source audit. The service describes the features as a place at which a service generally of interest to small craft or pleasure boats is available; the observed edition carries 29 distinct `Category_of_Small_Craft_Facility` values (fuel stations, boat ramps/launching places, camping sites, visitors moorings, nautical clubs, restaurants and combinations) over U37-series chart cells and is not a nationwide small-craft-facility inventory.

The source captures all native attributes and `OBJECTID` values, point XY in a bounded 250-ID page, count and ID snapshots before and after paging, and response bodies, wire bodies, and request receipts. Candidate generation retains the source CRS and coordinates without reprojection or geometry repair; the XY-only layer contract fails closed on flagged or unflagged Z/M ordinates. GeoParquet is the only candidate format; no display or lossy output policy is accepted.

USDOT BTS's current public IENC PDF item links the USACE Feature Classes service and master geodatabase; the earlier BTS map-service item returns an anonymous-access denial, so catalog succession remains unverified. The historical HIFLD inventory row and its DataLumos archive (project 240653) and the DHS crosswalk DOI (10.3886/E241367V1) all return HTTP 403 anonymously, so the archive crosswalk row and historical continuity remain unverified. Rights, source acceptance, baseline comparison, schema/ID/coverage contracts, and release approval remain false. The registered refresh schedule is stopped.
