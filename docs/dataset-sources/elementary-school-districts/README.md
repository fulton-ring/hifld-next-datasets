# Elementary School Districts — working local draft

The adapter reconstructs the complete official Census TIGER/Line 2026 elementary-school-district publication: **2,030 districts from all 25 published state ZIPs**. It retains all 15 original DBF attributes, original file-local `OGC_FID` values, native EPSG:4269 geometry, 1,930 Polygons and 100 MultiPolygons. No unified or secondary districts, invented territorial rows, replacement identifiers, reprojection or geometry repair are introduced. The complete directory, 25 original ZIPs and their retrieval receipts are preserved in `evidence/inputs`.

The main GeoPackage and GeoParquet contain original source attributes, file-local FIDs and native WKB only. Repeated FIDs across state files remain repeated. A separate, complete `metadata/source_record_lineage.jsonl` sidecar records the literal ZIP/member/raw SHA/GEOID/FID relationship for all 2,030 records. Leading-zero identifiers and leading characters are retained. Physical `ALAND`/`AWATER` integer fields never pass through floating point; the source driver's 1,988 blank/null `SDTYP` values are retained, with original DBF bytes available for physical representation.

The original producer ISO metadata defines boundaries operating on January 1, 2026. The official Gazetteer page independently enumerates the 25-state elementary district universe. Publication year 2026, creation month September and update month October do not establish an exact publication day. Each original ISO resource constraint states that TIGER/Line products are not copyrighted and requests Census acknowledgement. A tried older copyright URL returned 404; the original ISO constraints are the actual rights evidence.

The explicit Dagster source asset is registered in `elsd_source_integrity`; its monthly schedule remains **STOPPED**. Refresh preserves raw input attempts before receipt parsing, checks the complete pinned archive roster, physical fields, identifiers, coverage and native geometry, then builds privately. The reviewed shared construction protocol is sealed only after full private output validation and source/Git provenance checks. Cache reconciliation and construction share one lock. Missing or invalid original history fails closed; a permanent outside refusal journal records observed trust loss before candidate quarantine. An incomplete journal retains the untrusted candidate and blocks retries. Recovery requires exact trusted original outside witnesses and an original-manifest match; the pipeline does not create replacement trust from cache metadata.

All five complete historical published assets are pinned against collection size/MD5 and SHA256. Original assets remain at `/workspace/work/hifld-coordinator/64/baseline`; `evidence/baseline-pins.json` records immutable download locators. A diagnostic literal-GEOID comparison finds 1,963 common IDs, 67 source-only and eight historical-only IDs. This establishes a changed successor, not an accepted mapping. All original OID/OBJECTID/id occurrences remain recorded; no such identifiers are invented in the Census output. `compare_captured_baseline.py` replays the complete comparison. The GeoPackage/Parquet pair was compared across all shared typed values and native WKB. Historical SHP has 1,866 different WKB representations from the GeoPackage, with zero exact topological-equality differences and identical shared typed attributes; this does not establish 1,866 boundary changes. SHP/GeoJSON were fully read and checked separately, while PMTiles verification covers complete pinned bytes/header/metadata, not a per-tile equivalence claim.
