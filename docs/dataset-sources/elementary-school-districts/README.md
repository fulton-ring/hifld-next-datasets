# Elementary School Districts — working local draft

The adapter reconstructs the complete official Census TIGER/Line 2026 elementary-school-district publication: **2,030 districts from all 25 published state ZIPs**. It retains all 15 original DBF attributes, original file-local `OGC_FID` values, native EPSG:4269 geometry, 1,930 Polygons and 100 MultiPolygons. No unified or secondary districts, invented territorial rows, replacement identifiers, reprojection or geometry repair are introduced. The complete directory, 25 original ZIPs and their retrieval receipts are preserved in `evidence/inputs`.

The main GeoPackage and GeoParquet contain original source attributes, file-local FIDs and native WKB only. Repeated FIDs across state files remain repeated. A separate, complete `metadata/source_record_lineage.jsonl` sidecar records the literal ZIP/member/raw SHA/GEOID/FID relationship for all 2,030 records. Leading-zero identifiers and leading characters are retained. Physical `ALAND`/`AWATER` integer fields never pass through floating point; the source driver's 1,988 blank/null `SDTYP` values are retained, with original DBF bytes available for physical representation.

The original producer ISO metadata defines boundaries operating on January 1, 2026. The official Gazetteer page independently enumerates the 25-state elementary district universe. Publication year 2026, creation month September and update month October do not establish an exact publication day. Each original ISO resource constraint states that TIGER/Line products are not copyrighted and requests Census acknowledgement. A tried older copyright URL returned 404; the original ISO constraints are the actual rights evidence.
