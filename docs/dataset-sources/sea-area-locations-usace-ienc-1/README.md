# Sea Area Locations (USACE IENC)

The draft source is the `SEA_AREA_POINT` point layer (ID 22) in the USACE IENC Feature Classes MapServer. Its complete directly observed layer contained 1996 point features in EPSG:4326 within the inland chart extent recorded in the retained source audit. The service describes the features as a geographically defined part of the sea or other navigable waters that may be specified within its limits by its proper name; observed attributes include named inland navigable waters, so this is a regional chart-service layer, not a nationwide sea-area inventory. The sibling polygon product `SEA_AREA` is tracked separately as issue #305 and is not part of this draft.

The source captures all native attributes and `OBJECTID` values, native point XY coordinates in bounded 250-ID pages, count and ID snapshots before and after paging, and response bodies, wire bodies, and request receipts. Candidate generation retains the source CRS and point coordinates without reprojection or repair; the XY-only layer contract fails closed on flagged or unflagged Z/M ordinates and on points outside the declared layer extent or the EPSG:4326 domain. GeoParquet is the only candidate format; no display or lossy output policy is accepted.

USDOT BTS's current public IENC PDF item links the USACE Feature Classes service and master geodatabase; the earlier BTS map-service item returns anonymous-access denial, so catalog succession remains unverified. The historical HIFLD inventory row and its DataLumos archive (project 240627) return HTTP 403 anonymously, and the DHS crosswalk DOI (10.3886/E241367V1) redirects to its DataLumos archive (project 241367), which also returns HTTP 403 anonymously, so the archive crosswalk row and historical continuity remain unverified. Rights, source acceptance, baseline comparison, schema/ID/coverage contracts, and release approval remain false. The registered refresh schedule is stopped.
