# Sloped Ground Lines (USACE IENC)

The draft source is the `SLOPE_TOPLINE_LINE` polyline layer (ID 50) in the USACE IENC Feature Classes MapServer. Its complete directly observed layer contained 233 features in EPSG:4326 within the inland chart extent recorded in the retained source audit. The service describes the features as the upper marking of a slope, e.g. the ridge line or the separation line between two different gradients (S-57 Data Dictionary); the observed edition carries Category_of_Sloping_Ground `Cliff` over U37-series chart cells (U37CL007, U37CR149, U37MO000, U37TN450, U37TN518, U37TN564, U37TN606) and is not a nationwide sloped-ground inventory.

The source captures all native attributes and `OBJECTID` values, ordered XY paths in a bounded 250-ID page, count and ID snapshots before and after paging, and response bodies, wire bodies, and request receipts. Candidate generation retains the source CRS and path coordinates without reprojection or geometry repair; the XY-only layer contract fails closed on flagged or unflagged Z/M ordinates. GeoParquet is the only candidate format; no display or lossy output policy is accepted.

USDOT BTS's current public IENC PDF item links the USACE Feature Classes service and master geodatabase; the earlier BTS map-service item returns an anonymous-access denial, so catalog succession remains unverified. The historical HIFLD inventory row and its DataLumos archive (project 240651) and the DHS crosswalk DOI (10.3886/E241367V1) all return HTTP 403 anonymously, so the archive crosswalk row and historical continuity remain unverified. Rights, source acceptance, baseline comparison, schema/ID/coverage contracts, and release approval remain false. The registered refresh schedule is stopped.
