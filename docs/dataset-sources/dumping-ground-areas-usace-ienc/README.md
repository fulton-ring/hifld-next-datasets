# Dumping Ground Areas (USACE IENC)

The current USACE IENC Feature Classes service lists `DUMPING_GROUND_AREA` MapServer layer 95 and identifies USACE IENC as copyright holder. The observed layer contains one polygon, `OBJECTID` 1, with the declared source attributes preserved. The layer's chart extent is local around St. Louis; it is not a national dumping-ground inventory.

This draft captures the complete observed service-layer roster with request receipts and produces a native EPSG:4326 GeoParquet candidate without reprojection or geometry repair. It makes no claim of continuity with the archived DataLumos V1 inventory, an accepted release date, source rights, schema or ID contract, or nationwide coverage. Acceptance remains false and the refresh schedule is stopped.
