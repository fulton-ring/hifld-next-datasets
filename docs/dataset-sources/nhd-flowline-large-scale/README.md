# NHD Flowline - Large Scale source record

- Inventory ID: `nhd/flowline-large-scale-2` ("Flowline - Large Scale", agency US Geological Survey, date_issued 2024-03-20; the inventory's "modified 2025-07-03" is the rescue-archive edit date, not a data release). Issue #220. No pipeline is implemented for this dataset: the exact producer publication is a retired historical release and no currently maintained agency publication recreates it. The supervisor's planning note on the issue (2026-11-13) accepted the implementation research finding (no maintained source; nothing currently published recreates this layer) and routed this card to the documentation-only park/provenance PR flow — no pipeline build, no publication; release schedules stay stopped.
- Crosswalk match: the DHS HIFLD Open crosswalk (DOI 10.3886/E241367V1) resolves to `www.datalumos.org` (DataLumos/ICPSR is a banned fetch host under the source policy), so it was not downloaded; the mapping was verified directly against the producing agency's live services. The sha256-verified crosswalk copies documented on this repository (byte copy sha256 `7f3394fed2712fdcc176b7ce658293fdded656b9b719f0d90154c07dc38772bc`, cited on #255/PR #806) consolidate the NHD-family rows into one "3D Hydrography Program (3DHP) Layers" row (Open ID `650c07e542fa43b6a327c7f683681712`, status Deprecate) whose external landing is the USGS `usgs_3dhp_all` FeatureServer. The HIFLD inventory description for this row is the USGS NHD service description as captured for the January 2024 snapshot (it carries the snapshot's "Data Refreshed January, 2024" line), prefixed with the producer's own successor note "Please use 3DHP for updated data"; the live service description (2026-11-13) now additionally carries a temporal-change use-constraints paragraph and a "Data Refreshed October, 2026" stamp. The inventory Download Location is the DataLumos project 240110 third-party mirror, which was never fetched.
- Exact producer publication (identified, not used as a pipeline input): USGS NHD MapServer layer 6 "Flowline - Large Scale", `https://hydro.nationalmap.gov/arcgis/rest/services/nhd/MapServer/6` — `esriGeometryPolyline`, `hasZ`/`hasM` true, served Web Mercator (wkid 102100 / EPSG:3857), anonymous REST, `maxRecordCount` 2000, ArcGIS Server currentVersion 11.3. The service also hosts the sibling legacy layers 4 "Flowline - Small Scale" (a separate inventory entry, #221) and 5 "Flowline - Small Scale (HI, PR, VI, Pacific Territories)" (#222); the maintained 3DHP flowline publication is its own inventory entry `nhd/flowline` (#219, merged pipeline #816). None of those is in scope here.
- Dated anonymous extraction evidence (2026-11-13, re-verified by this run): **30,221,659** features (`returnCountOnly`, two agreeing probes), so a complete paginated extraction needs at least 15,111 requests at `maxRecordCount` 2000; sampled rows carry `resolution` 2 (NHD high resolution, 1:24,000-scale) with 14-character NHD `reachcode` values (e.g. "06010103004919"), `permanent_identifier` and `globalid` GUIDs, `ftype`/`fcode` (e.g. 460 StreamRiver / 46006); 18 fields as served: `OBJECTID`, `permanent_identifier`, `fdate`, `resolution`, `gnis_id`, `gnis_name`, `lengthkm`, `reachcode`, `flowdir`, `wbarea_permanent_identifier`, `ftype`, `fcode`, `Shape`, `innetwork`, `mainpath`, `visibilityfilter`, `Shape_Length`, `globalid`; full-national extent in Web Mercator including Alaska, Hawaii and Puerto Rico. Sampled `fdate` values span 2011-12-19 to 2021-03-18 — feature-level edits ended with NHD stewardship; observed ≈1.8 KB/feature wire size puts a complete raw REST capture in the ≈50–55 GB JSON range.
- Retirement evidence (checked 2026-11-13): USGS states "As of October 1, 2023, the NHD was retired. NHD data will continue to be available, but no longer maintained. The most current data will be available through the 3D Hydrography Program (3DHP)" (https://www.usgs.gov/national-hydrography/national-hydrography-dataset); the 3DHP access page classifies the legacy NHD services/downloads as "no longer updated and maintained", provided for reference (https://www.usgs.gov/3d-hydrography-program/access-3dhp-data-products). The October 2026 "Data Refreshed" line is periodic republication of the same static legacy content, not data stewardship (HIFLD's own snapshot recorded "Data Refreshed January, 2024" for the same service). A prior independent review in this dataset family (PR #806) ruled the retired reference publication unacceptable as a pipeline source.
- Maintained-successor checks (checked 2026-11-13): the USGS 3DHP_all FeatureServer (`https://3dhp.nationalmap.gov/arcgis/rest/services/usgs_3dhp_all/FeatureServer`, national "Flowline" layer 50, 30,251,533 features, quarterly updates, recorded in `docs/dataset-sources/nhd-flowline/README.md`) is the maintained successor flowline product, but it is elevation-derived hydrography carrying the 3DHP data model (`id3dhp`, `featuredate`, `mainstemid`, ...; no NHD `permanent_identifier`/`reachcode`) and does not recreate this entry's NHD high-resolution schema/IDs; it is already tracked as `nhd/flowline` (#219), so pointing #220 at it would duplicate #219's dataset under a second slug. EPA NHDPlus V2 is custodian of the 1:100,000 medium-resolution NHD only (2012 static snapshot; frozen) and cannot recreate a 1:24,000-scale layer. NHDPlus High Resolution is 1:24,000-scale but covers CONUS/Hawaii/territories and only portions of Alaska (this service layer includes all of Alaska), and its per-region NHD copies are varying-vintage snapshots, not the seamless maintained NHD. No currently published, maintained dataset recreates this layer.
- Mirror policy: the DataLumos/ICPSR archive entry cited by the inventory is a third-party mirror and was never fetched; no archive, mirror or HIFLD rescue copy is a pipeline candidate for this dataset.
- Audit trail: no ingest, catalog or publish assets exist for this dataset and none were created; no raw capture was made; nothing was published. This file is the only change this issue contributes to `main` pending the supervisor/maintainer disposition.
