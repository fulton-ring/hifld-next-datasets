# Land Region Locations (USACE IENC)

This draft captures the complete official USACE IENC `LAND_REGION_POINT` MapServer layer 12 (3,816 observed points) and preserves the service-declared fields, native OBJECTIDs, distinct non-null `Feature_ID` values, source attribute strings (including the 3,749 empty `Category_of_Land_Region` values), and EPSG:4326 XY coordinates. Its typed GeoParquet candidate is unapproved. No accepted historical baseline, cross-refresh ID stability, release date, rights, coverage contract, or release decision is established.

The producer is the US Army Corps of Engineers (USACE) Army Geospatial Center (AGC) Inland Electronic Navigational Charts (IENC) Program, whose official public website is <https://ienccloud.us/> (contact AGC-IENC@usace.army.mil). The layer is published by the official IENC Feature Classes service (`https://ienccloud.us/arcgis/rest/services/IENC_Feature_Classes/LAND_REGION_POINT/MapServer/12`, copyright `USACE IENC`); the `USACE_IENC_Master_Service` MapServer lists the same `LAND_REGION_POINT` feature class at layer 12, and service metadata states the S-57 IENC database is extracted to an Esri File Geodatabase for publication. USDOT BTS NTAD item `7ec34864c8804468a9cf52d437fe4b6c` ("Inland Electronic Navigational Charts", public PDF) documents bi-monthly USACE/AGC updates and explicitly links this service and the master file geodatabase; that item is the recorded official distribution delegation, not a source of truth.

Dated probes (2026-11-07): the complete layer was extracted anonymously in 16 bounded 250-OBJECTID page queries (service `maxRecordCount` 2,000); counts and before/after ID rosters bracketed the extraction; observed point bounds equal the declared layer extent. `Feature_ID` is non-null and distinct in all 3,816 rows in this snapshot; its stability across refreshes is unverified. The draft gates now pin both verified snapshot properties: a null or duplicate `Feature_ID`, or any contraction/expansion of the observed point bounds, fails readiness and quarantines the raw capture unchanged pending an explicit versioned contract. `Source_Date` strings span 20010117–20260115, which is feature source-date coverage, not a dataset release date. No layer-level release date is declared; the DataLumos inventory archive modification date (2025-04-08) is not a source release date.

The historical archive fallback is DataLumos "HIFLD OPEN Land Region Locations (USACE IENC)" (project 239405, DOI 10.3886/E239405V1, released 2025-10-29; GeoJSON/Shapefile zips plus metadata.xml; anonymous direct download returned HTTP 403 from this environment). It is a third-party rescue copy of the retired HIFLD Open portal, not a maintained agency feed, and is never a pipeline input. The DHS HIFLD OPEN GIS Data Index and Crosswalk (DOI 10.3886/E241367V1) exists and was verified at the study level, but its crosswalk row could not be inspected anonymously (HTTP 403); the match to this inventory entry is by exact inventory ID/title and the IENC layer description, consistent with prior USACE IENC audits that found the crosswalk's IENC REST links answering at the service level with changed layer IDs. The separate `LAND_REGION_AREA` polygon feature class belongs to the sibling inventory entry `land-region-areas-usace-ienc-2`, not this dataset.

The draft Dagster asset `land_region_locations_usace_ienc` stages a source-faithful candidate with completeness, schema/ID, CRS, coverage and drift quarantine gates; every approval flag (source release, freshness, schema/ID contract, coverage, rights, mapping, baseline, release) remains false pending maintainer decisions. Refresh schedule remains STOPPED; no production release is authorized. Research details are in [source.json](source.json); machine-readable runtime provenance is written by the pipeline into `metadata/source_manifest.json`, `metadata/source_audit.json` and `metadata/candidate_ready.json`.
