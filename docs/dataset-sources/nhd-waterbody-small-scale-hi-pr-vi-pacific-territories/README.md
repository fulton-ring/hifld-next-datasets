# NHD Waterbody - Small Scale (HI, PR, VI, Pacific Territories) source record

- Inventory ID: `nhd/waterbody-small-scale-hi-pr-vi-pacific-territories-2` (issue #232). No pipeline is implemented for this dataset: the exact producer publication is a retired historical release and no currently maintained agency publication recreates it. Park/retire is a supervisor decision (`needs_decision`: "no maintained source: park or retire").
- Crosswalk match: the DHS HIFLD Open crosswalk (DOI 10.3886/E241367V1) resolves to `www.datalumos.org` (DataLumos/ICPSR is a banned fetch host under the source policy), so it was not downloaded; the mapping was verified directly against the producing agency's live services. The HIFLD inventory description for this row is the USGS NHD service description verbatim, prefixed "Please use 3DHP for updated data", with agency "US Geological Survey"; the inventory Download Location is the DataLumos project 240403 third-party mirror, which was never fetched.
- Exact producer publication (identified, not used as a pipeline input): USGS NHD MapServer layer 11 "Waterbody - Small Scale (HI, PR, VI, Pacific Territories)", `https://hydro.nationalmap.gov/arcgis/rest/services/nhd/MapServer/11` — polygon layer, served Web Mercator (102100/3857), anonymous REST, maxRecordCount 2000. The service also hosts the CONUS sibling layer 10 "Waterbody - Small Scale" (a separate inventory entry). Live checks 2026-11-13: 7,871 features (`returnCountOnly`); FDate 1994-01-01..2014-12-23 (live `outStatistics` min/max); sampled `Resolution` "High"; `ComID` values in the NHDPlusV2 territory range (80004xxxxx); 24 fields OBJECTID, Shape, Permanent_, FDate, Resolution, GNIS_ID, GNIS_Name, AreaSqKm, Elevation, ReachCode, FTYPE, FCode, ComID, OnOffNet, PurpCode, PurpDesc, MeanDepth, LakeVolume, MaxDepth, MeanDUsed, MeanDCode, LakeArea, Shape_Length, Shape_Area. Approximate per-territory live envelope counts (4326 bounding boxes): Hawaii 3,192; Puerto Rico 3,663; US Virgin Islands 435; Guam 502; CNMI 58; American Samoa 21. Service copyright reads "USGS TNM – National Hydrography Dataset.  Data Refreshed October, 2026."
- Retirement evidence (checked 2026-11-13): USGS states "As of October 1, 2023, the NHD was retired. NHD data will continue to be available, but no longer maintained. The most current data will be available through the 3D Hydrography Program (3DHP)" (https://www.usgs.gov/national-hydrography/national-hydrography-dataset); the 3DHP products page classifies the legacy NHD services and downloads as "no longer updated and maintained" and provided "for reference purposes" (https://www.usgs.gov/3d-hydrography-program/access-3dhp-data-products). The October 2026 "Data Refreshed" line is periodic republication of the same static legacy content, not data stewardship: the layer's own content is frozen (FDate ends 2014-12-23). A prior independent review in this dataset family (#806) and the sibling source record for `nhd/area-small-scale-hi-pr-vi-pacific-territories-2` (#217, PR #813) ruled the retired reference publication unacceptable as a pipeline source.
- Maintained-successor check (checked 2026-11-13): the USGS 3DHP_all FeatureServer (`https://3dhp.nationalmap.gov/arcgis/rest/services/usgs_3dhp_all/FeatureServer`, currentVersion 11.3, service refreshed 2026) publishes a national "Waterbody" polygon layer (layer 60, 7,158,943 features) with quarterly EDH additions. Its HI/PR/VI/Pacific-territories content, however, is exclusively legacy NHD carry-over, not maintained 3DHP production: every waterbody inside the Hawaii and Puerto Rico territory envelopes carries `workunitid` "NHD" with a single `featuredate` 2023-09-14 (live group-by counts: Hawaii envelope 3,170 features in one "NHD" work unit; Puerto Rico envelope 3,366 in one "NHD" work unit), and the carried-over territory population is incomplete relative to the legacy layer (live envelope counts: Hawaii 3,170 vs 3,192; Puerto Rico 3,366 vs 3,663; US Virgin Islands 373 vs 435; Guam 245 vs 502; American Samoa 7 vs 21). The 3DHP data model (OBJECTID, id3dhp, featuredate, mainstemid, gnisid, gnisidlabel, featuretype, featuretypelabel, areasqkm, workunitid, Shape__Length, Shape__Area) drops the legacy NHD small-scale schema (Permanent_, Resolution, FTYPE, FCode, ComID, ReachCode, GNIS_ID/Name, lake depth/volume fields), and 3DHP publishes no small-scale cartographic variant and no territories-specific product. The 3DHP FY26 staged downloadable product covers Alaska and CONUS only. The 3DHP Waterbody layer is tracked as its own inventory entry; a partial substitute for this row would require an explicit maintainer decision.
- EPA NHDPlusV2 check (checked 2026-11-13): territory VPUs exist (HI VPU 20, PR/VI VPU 21, American Samoa/Guam/CNMI 22AS/22GU/22MP) with NHDSnapshot shapefile components under `https://dmap-data-commons-ow.s3.amazonaws.com/NHDPlusV21/Data/` (EPA pages: `https://www.epa.gov/waterdata/nhdplus-hawaii-data-vector-processing-unit-20`, `https://www.epa.gov/waterdata/nhdplus-puerto-rico-us-virgin-islands-data-vector-processing-unit-21`), but the territory content is a frozen historical build: initial release 12/30/2014 from a 2014 high-resolution NHD extract (NHDPlusV2 User Guide, 2019-03-13, footnote 1); last content updates 11/18/2015 (HI and PR/VI NHDSnapshot) and 05/10/2016 (PR/VI WBD pointers); nothing since. The NHD ingredient itself was retired by USGS in 2023. This is not a currently maintained publication.
- Mirror policy: the DataLumos/ICPSR archive entry cited by the issue is a third-party mirror and was never fetched; no archive or mirror is a pipeline candidate.
- Audit trail: no ingest, catalog or publish assets exist for this dataset and none were created; this file is the only change this issue contributes to `main` pending the supervisor decision (consistent with the sibling disposition on #217).
