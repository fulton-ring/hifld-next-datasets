# Opt-in native GeoParquet catalog fallback

Issue #417, PR #421. Public processing source `84c933e3b71382d9449839289e14f590aa2b38c9`; coordinator https://chatgpt.com/local/01a15273-e90b-7211-b493-3ad4668ed0e8. This is proposed draft machinery, not source, contract, baseline, rights, geometry-exception or release acceptance.

A version with no canonical/legacy/tabular source can now be cataloged/discovered from **one explicitly pinned `prebuilt_output_policy.formats.geoparquet` object**. The existing policy's exact complete roster, SHA256 and byte length are mandatory. Canonical GPKG/Float32 and unknown/CSV precedence remain; corrupt or ambiguous raw sources are not masked. Ordinary derived-only Parquet folders remain ignored. No global source-format reclassification, alternate source directory or lossy GeoPackage conversion is introduced.

`native_geoparquet_catalog.py` implements selection, stable snapshots/manifest identity, exact local-byte pins, and a single remote native-object download. Local aliases are rejected before hashing their targets. Source manifest layers are checked with bounded snapshot-bound range reads. GCS discovery can require a complete read of each opted-in native object; it does not trust an asserted SHA metadata label. Remote cataloging avoids downloading raw captures or duplicating the selected native file.

Catalog dictionaries sample at most5000 rows/64MiB directly in Arrow. Literal attribute names, nested physical schemas, field metadata and complete schema IPC are retained. Ordinary attributes named `geometry` or `wkb_geometry` are preserved independently of the declared primary geometry. Decimal128/256 ranges/examples remain exact strings with precision/scale; integer ranges remain Python integers, preserving IDs beyond2**53; Float32 values/widths and Date32 remain explicit. Attribute statistics are sample statistics, not full-population attribute verification.

Every row is scanned in bounded Arrow batches for geometry/population counts, nulls/empties/invalids and native bounds. Tail invalid/null geometries after row5000 block quality. GeoParquet1.0/1.1, one WKB geometry column and planar edges are supported. Omitted CRS follows normative GeoParquet CRS84; explicit null/unknown CRS is rejected. Declared geometry types/bounds are reconciled. Native coordinates are not reprojected, repaired or simplified.

The128MiB decoded-batch ceiling is checked **after** Arrow allocation; this is not a hard RSS limit. Multiple prebuilt objects, multiple declared geometry columns, non-WKB and spherical encodings require another reviewed adapter. All prior release/comparison/provenance/CAS gates remain mandatory; native catalog eligibility grants no acceptance.
